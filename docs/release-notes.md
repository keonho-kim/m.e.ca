# M.E.CA — Minimal Essentials Coding Agent

Go 실행 파일 하나로 코딩 작업을 수행한다. macOS·Linux의 amd64·arm64를 지원한다.

## 이번 릴리스

- **파일 편집·저장**은 서버와 WebUI 모두 최대 **2MiB UTF-8** 문서를 지원한다. 입력과 붙여넣기에 같은 바이트 한도를 적용하며, 초과 파일은 읽기 전용 페이지로 본다. 저장은 revision을 확인하고, 저장 응답을 기다리는 동안 추가한 편집도 미저장 상태로 유지한다.
- **편집기**를 react-simple-code-editor로 교체했다. Astryx 문법 강조와 키보드 undo/redo를 제공하며 한글 등 IME 조합을 한 번의 실행 취소로 처리한다. Preview/Raw 전환은 현재 초안을 보여주고 입력 이력을 유지한다.
- **대용량 편집**은 고정 높이 textarea와 단일 대량 입력 트랜잭션을 사용한다. 문법 분석은 연속 입력을 합쳐 처리하고 토큰 예산을 넘으면 중단한다. 중복 원문 DOM·불필요한 스토어 알림을 줄이며 문서 전환 시 이력과 강조 Range를 해제한다.
- **파일 관리**는 오른쪽 목록의 항목별 메뉴에서 참조 추가·이름 변경·삭제를 제공한다. 드래그 앤드 드롭으로 폴더에 이동할 수 있다. 서버는 파일 변경과 에이전트 쓰기를 조정하고, 변경된 경로를 저장된 참조에 반영한다.
- **모델 설정**은 대화 선택 없이 전역 기본 모델을 저장하고 모델 ID 필드에서 현재 주소의 후보를 자동 조회한다. 동시 설정 변경 중에도 진행 중인 요청의 모델 연결을 유지한다.
- **채팅과 컴포저**는 컨테이너 폭의 80%를 사용하고 답변·Thinking·도구 셀은 그 안의 가용 너비를 유지한다. 중복 좌우 여백을 제거하고 긴 텍스트·코드·표는 가로 스크롤 없이 줄바꿈한다. 실행 중 빈 입력의 전송 버튼은 중지로 바뀌고, 추가 텍스트는 방향 수정으로 보낸다. `⌘↵` 또는 `Ctrl+↵`로 후속 요청을 예약한다.
- **참조 표시**는 파일·폴더·스킬에 아이콘을 포함한 Astryx 채팅 토큰을 사용한다. 전송한 사용자 메시지에도 엔진용 참조 안내 문장 대신 토큰을 표시한다. 참조를 추가하면 현재 파일·스킬 화면을 유지하고 메시지를 전송한 뒤 대화로 이동한다.
- **완료 정보**는 마지막 응답 뒤에 입력·출력 토큰·TPS·총 소요 시간을 표시하며 중간 응답과 완료 통계가 섞이지 않도록 했다. 성공 완료의 녹색 점을 제거하고 컴포저 아래에는 상태 문구 없이 메모리·토큰·시간·처리량을 표시한다.
- **설정 저장**은 모델·실행 설정의 저장 버튼에서 네/아니오 확인 창을 연다. 저장 성공 후 설정 창까지 닫으며 실패하면 오류와 입력을 유지한다. 설정의 파일·스킬 바로가기를 제거하고 파일 목록의 하위 폴더 경로 글자 크기를 조정했다.
- **스트림과 저장소**는 긴 Thinking의 자동 스크롤과 저장 이력 전환을 보강했다. 실시간·저장 추론의 표현을 통일하고 빈 스트림 셀을 숨겨 도구 호출 시 깜빡임을 줄였다. 재접속 스냅샷과 대기 델타의 중복을 제거하고, SQLite 누적 사용량은 새 기록만 집계한다. 대화 삭제·파일 변경 후 관련 캐시와 참조를 정리한다.
- **내장 UI 배포**는 gzip 자산과 manifest를 단일 묶음으로 발행해 빌드 중 파일 누락을 방지한다. 변경 없는 압축 결과를 재사용하고 지난 캐시는 회수한다. 배포 실행에는 프론트 소스나 Bun·Node가 필요 없다.
- **의존성**은 Go 1.27.4·Bun 1.4.4와 Astryx 안정판 0.7.13에 맞췄다. Astryx Lab 의존성은 제거했으며 tui/full 배포 구분과 네 플랫폼 지원을 유지한다.

## 배포

| 종류 | 포함 기능 |
| --- | --- |
| `tui` | TUI·CLI, 모든 Provider·도구·스킬·팀 모드 |
| `full` | tui의 모든 기능과 SSE·WebSocket·gRPC 서버·내장 WebUI |

파일명은 `meca_<version>_<tui|full>_<platform>.tar.gz`다. 각 종류에 네 플랫폼을 제공하며 여덟 아카이브와 공용 `checksums.txt`를 게시한다. `meca --help` 첫 줄로 종류를 확인한다.

```sh
meca upgrade --tui
meca upgrade --full
```

지정한 종류의 최신 정식 배포본으로 교체한다. 옵션 없는 `meca upgrade`는 현재 종류를 유지하며 설정·모델 연결·인증정보·대화를 보존한다. 기본 프롬프트는 배포 기본본으로 갱신한다.

## 실행

- `meca [path]`: 프로젝트 TUI
- `meca --print`: 최종 답변 출력
- `meca --mode json`: 순서 있는 JSONL 이벤트 출력
- `meca --session ID`: 저장 대화 재개
- `meca --session ID --export`: 원본 이력 JSONL 내보내기
- full의 `meca --server --ui`: 내장 WebUI 기동
- full의 `meca --server --protocol sse|socket|grpc`: 자체 서버 API 기동

배포 실행에는 Go·Bun·Node·별도 프론트 서버가 필요 없다. full은 빌드된 정적 프런트 자산과 브라우저 라이선스 고지를 포함하며 tui는 서버와 WebUI를 포함하지 않는다.

## 팀과 스킬

`!team`은 현재 대화의 팀 모드를 전환한다. 독립 세션 두 개로 시작하고 필요한 동료를 초대·복구해 동시에 최대 여덟 개가 협업한다. 공용 대화·담당 경로·도구 진행을 공유하며 개인 Thinking은 공개 스트림에 내보내지 않는다.

`!skills`는 스킬 목록·출처·설명·본문을 조회한다. `#스킬명`으로 지침을 지정하거나 에이전트가 필요한 스킬을 탐색한다. 프로젝트 `.agents/skills/`, 개인 `~/.meca/skills/`, 공유 `~/.agents/skills/`를 순서대로 사용한다. 기본 스킬은 `create-skill`·`ui-design`·`backend-design`이며 기존 사용자 파일을 보존한다.

## WebUI와 서버

WebUI는 작업공간별 대화 탐색·생성·삭제, 독립된 다중 세션 실행, 스트리밍 응답·도구 활동·승인, 모델·실행·일반 설정을 제공한다. 문법 강조 편집과 명령·스킬 후보를 지원하며 좁은 창에서는 파일·스킬 목록과 본문을 전환한다. 기본 라이트와 다크·시스템 테마, 흑백 중심의 표면과 의미별 상태색, 축소 모션을 사용한다.

서버는 작업 수명을 소유한다. 관찰 연결이 종료돼도 접수한 작업을 계속 실행한다. `--concurrency`는 프로세스 전체의 동시 사용자 작업 수를 지정한다. 세션별 쓰기 소유권, 접수 키 중복 방지, 승인·취소·방향 수정·후속 예약과 커서 재구독을 제공한다. 스트림은 5초 무출력 후 1초마다 heartbeat를 보낸다.

서버 토큰 인증·TLS·허용 Host/Origin을 지원하며 WebUI는 HttpOnly 쿠키를 사용한다. 리스너가 준비되면 현재 서버 토큰을 stdout에 한 번 표시하며 연결 화면에 이 값을 입력한다. 운영 로그·이벤트·URL에는 토큰을 포함하지 않는다. API는 MECA 자체 계약을 사용한다. 모델 연결용 OpenAI·OpenAI 호환 Provider는 별도로 지원한다.

## 저장과 보안

대화·도구 결과·사용량은 로컬 SQLite에 보존한다. 큰 원문은 참조·압축하고 세션·작업별 데이터를 구분한다. 지원하지 않는 저장 형식은 원본을 보존한 채 오류를 반환한다.

API Key는 암호화해 저장하고 OS 자격 증명 저장소와 내부 주기적 키 교체를 사용한다. 비밀값은 프롬프트·로그·저장 이벤트에서 제외한다. 실행 종료·취소 시 조회·스트림·타이머·임시 파일·DB와 프로세스 자원을 정리하며 서버 입력·출력·캐시·저장소에는 개별 자원 예산을 적용한다.
