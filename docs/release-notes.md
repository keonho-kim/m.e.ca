# M.E.CA v0.0.20261120

- **TUI 우상단 TPS**는 현재 모델 호출의 속도를 보여줍니다. 첫 출력까지는 대기 시간을, 그 뒤에는 서버가 보고한 생성 속도나 토큰 수신 속도를 표시합니다. 속도를 계산할 표본이 부족하면 `—`를 표시합니다. 팀 모드에서는 현재 측정 중인 팀원 이름을 함께 보여주고, 작업 전체 평균은 완료 요약에 표시합니다. [사용량 표시](https://github.com/keonho-kim/m.e.ca/blob/v0.0.20261120/docs/usage.md#화면과-사용량)
- **OpenAI·LM Studio Responses**에서 스트림 조각과 최종 본문을 대조해 같은 답변이 반복 표시되거나 끝부분이 누락되는 문제를 수정했습니다. 완료 이벤트에만 들어 있는 답변도 한 번 저장합니다.
- **Thinking만 반환한 호출**이 답변이나 완성된 도구 호출 없이 정상 종료되면 초안을 유지하고 한 번 교정을 요청합니다. 출력 토큰 한도로 답변이 잘린 경우에는 자동 출력 설정의 vLLM 텍스트 요청에서 후속 요청의 여유 토큰을 확인한 뒤, 도구 없이 한 번 이어 씁니다.
- **웹 문서 조회** 기능을 추가했습니다. `web_fetch`는 HTML을 전용 Chromium에서 렌더링하고 본문을 Markdown 페이지로 전달합니다. 호스트에 Chrome이나 Chromium이 준비되면 솔로·팀, TUI·서버·비대화형 실행에서 사용할 수 있습니다. 다음 페이지는 결과 ID와 커서로 이어 읽습니다.
- **자동 문맥 압축**은 유효 컨텍스트 창의 75%에 도달하면 압축 가능한 이전 이력을 요약합니다. vLLM에서 다음 요청의 토큰 수를 확인할 수 있으면 해당 수치를 사용합니다. 압축 요약의 기본 출력 상한은 유효 창의 7%입니다. 호출 기록에서 압축 전후 입력 토큰 수와 측정 출처, 적용된 출력 예산을 확인할 수 있습니다. 기존 `[compaction]` 설정에 `reserve_tokens`가 있으면 해당 줄을 제거하세요. [호출별 진단](https://github.com/keonho-kim/m.e.ca/blob/v0.0.20261120/docs/diagnostics.md#운영-로그)
- **스트림 복구**는 답변이 시작된 뒤 발생한 일시적 연결 오류에도 작동합니다. 재시도 중 기존 답변을 유지하고 새 내용부터 이어 보여줍니다. 형식이 잘못된 도구 호출은 검증 오류와 함께 모델에 돌려줘 교정합니다. Chat Completions에서 `stop`이나 `tool_calls`를 받은 뒤 연결이 정상 종료되면 응답과 최종 사용량을 확정합니다.
- **문맥과 저장 처리**에서 인코딩된 모델 요청을 재사용하고, 메타데이터를 스트리밍으로 읽으며, 필요한 SQLite 본문과 웹 관찰 페이지만 가져옵니다. 작업 중 아직 읽지 않은 관찰은 압축 뒤에도 이어 볼 수 있습니다.
- **기본 스킬**에 `#application-best-dev-practices`를 추가했습니다. 18개 앱 유형의 구현 흐름, 권한, 상태, 실패 복구를 다룹니다. `#ui-design`에는 컴포넌트 선택, 직접 조작, 모션, 로딩·오류 피드백 지침을 보강했습니다.
- **설정 초기화**가 작업 취소를 반영하고 기본 스킬을 저장할 때 디렉터리와 파일의 대상을 검사합니다.
- **문서 개편**으로 공통 도구 14종과 팀 전용 도구 6종의 역할·사용 조건을 한곳에서 확인할 수 있습니다. 도구 등록부터 승인·실행·결과 저장까지의 코어 흐름과 브라우저 조작·WebFetch의 연결 경로를 정리했습니다. 스킬 사용·작성과 배포 기본 스킬의 구성·초기화를 각각의 문서에서 다룹니다.
