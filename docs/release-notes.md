# M.E.CA — Minimal Essentials Coding Agent

Go 실행 파일 하나로 TUI·CLI·서버에서 코딩 작업을 수행한다. 배포 대상은 macOS·Linux의 amd64·arm64다.

## 이번 릴리즈 주요 변경

- 배포를 `tui`와 `full`로 나눴다. tui는 TUI·CLI와 공통 Provider·도구·스킬·팀을 유지하며 서버 어댑터·WebUI 자산은 컴파일에서 제외한다. full에는 서버·내장 화면을 포함한다. 같은 날짜 태그에 각 네 플랫폼, 총 여덟 압축 파일과 공용 체크섬을 제공한다.
- 파일명은 `meca_<version>_<tui|full>_<platform>.tar.gz`다. `meca --help`에 종류를 표시한다. `meca upgrade --tui`와 `--full`은 지정한 종류의 최신 배포본으로 전환하고, 옵션을 생략하면 현재 종류를 유지한다. 설정·대화는 보존한다. `./install.sh tui`는 Bun 없이 빌드하며 인자 없는 소스 설치는 full이다. 새 이름·옵션을 모르는 기존 실행 파일은 새 배포본으로 한 번 직접 재설치해야 한다.
- `meca --server --ui`로 React·Astryx WebUI를 제공한다. 프론트 자산과 라이선스 고지를 배포 바이너리에 포함하므로 실행할 때 Bun·Node·별도 프론트 서버가 필요 없다. 기본 라이트와 다크·시스템 테마, 흑백 중심의 glass 표면, 모션 감소와 Lucide 아이콘을 제공한다.
- 작업공간별 펼침/접힘과 대화 탐색·생성·삭제, 여러 프로젝트/대화의 독립 실행, 스트리밍 답변·Thinking·도구 활동·승인·후속 예약을 연결했다. `!` 명령과 `!dir` 참조 선택, 스킬 탐색, revision을 확인하는 문법 강조 파일 편집, 모델·실행·일반 설정을 지원한다.
- TUI와 WebUI에 이미지 붙여넣기를 연결하고 WebUI는 드래그 앤드 드롭도 지원한다. 이미지 입력을 확인한 모델에 전달하며 이미지당 64MiB·64M픽셀, 요청당 최대 8개·128MiB를 적용한다. 저장 이미지는 인증된 256px 썸네일로 표시하고 원본은 열 때 가져온다.
- 서버에 작업공간 등록, 세션별 조회·설정·닫기, 모델 탐색·진단, 파일 편집·감시, 명령 후보·해석, 불확실한 접수 조회를 추가했다. `--concurrency`는 제품 고정 상한 없는 양의 정수이며 모든 작업공간이 실행 슬롯·첨부·이벤트·파일 효과 잠금을 공유한다. 팀 전체 스트림과 승인 입력, 스트림 일시정지·커서 재구독을 제공한다.
- 입력 용량 계산을 변경분으로 갱신하고 대화·파일·스킬·예약 목록과 긴 코드 표시의 DOM을 제한했다. 이벤트를 묶어 처리하고 필요한 조회만 갱신하며, 비활성 캐시·완료 작업·Blob URL·취소된 읽기를 회수한다. SQLite 목록 메타데이터·디렉터리 revision 캐시와 세션별 요청 인덱스, 큰 읽기·출력의 별도 예산·JSON 압축으로 반복 I/O와 할당을 줄였다.
- 재연결 중 후속 예약 누락, 대화 목록 커서 고갈, 런타임 회수 후 기본 모델 누락과 다른 클라이언트의 대화·모델 변경 반영 누락을 수정했다. 모델 호출과 원문·초안의 상태를 분리해 도구 결과의 순간 표시, 완료 이력 인계와 중복 접수를 보강했다.
- SQLite 미리보기와 트랜잭션 인코딩의 교착, 증분 로그 저장 실패·마스킹 변경 시 상태 오염, 팀원 복귀 시 초안 generation 재사용을 수정했다. 세션·작업 소유 관계, 저장 충돌, 이미지 전용 이력·없는 이미지의 404, 원문 복원·초안 spool 실패와 취소 시 자원 반환을 보강했다.
- Go 전체 테스트·관련 race 검사와 프론트 단위 테스트 28개·브라우저 시나리오 15개로 검증했다. 로컬 측정에서 짧은 작업의 API 호출은 13회에서 6회, 1만 줄 파일의 미리보기 DOM은 5,442개에서 237개로 줄었다. 측정 조건과 범위는 [개발 가이드](https://github.com/keonho-kim/m.e.ca/blob/main/docs/development.md#내장-webui)에 기록했다.
- 기본 `ui-design` 스킬의 구현 확인에는 Playwright CLI로 실제 화면·상호작용을 검증하는 지침을 보강했다.

## API 연동 변경

- 서버는 MECA 자체 API만 제공한다. 서버용 OpenAI 호환 엔드포인트·추가 옵션은 제거했으며 모델 연결용 OpenAI·OpenAI 호환 Provider는 유지한다.
- `detail` 응답의 Base64 `data`를 제거하고 UTF-8 `text`를 제공한다. offset·nextOffset·totalBytes는 바이트 기준이며 후속 페이지는 같은 revision을 사용한다. 디렉터리 후속 페이지도 첫 응답의 revision을 전달한다. Go·TypeScript 생성 타입을 함께 갱신했다.
- SSE는 선택한 작업공간·대화의 본문을 전송하고 공통 제어 사건을 유지한다. 생략한 본문의 커서는 `event: cursor`로 전달하며 5초 무출력 후 1초 heartbeat를 유지한다. WebUI 인증은 원문 서버 토큰을 브라우저 저장소에 남기지 않는 만료형 HttpOnly 쿠키를 사용한다.
- 기존 클라이언트는 [서버 API](https://github.com/keonho-kim/m.e.ca/blob/main/docs/server.md)와 [WebUI 연동 계약](https://github.com/keonho-kim/m.e.ca/blob/main/docs/webui-api.md)에 맞춰 요청·이벤트 처리를 갱신한다.

## 안정성과 자원 관리

- 메시지·오류 코드·이벤트·레벨·복구 문구를 중앙 diagnostics에 모으고 raw 로거·임의 진단 선언을 개발 검사에서 차단한다.
- 출력 장애의 health 신호, 제한된 반복 경고·주기 집계, 비차단 stderr 중계의 종료·합류와 중단된 로그 회전 정리를 제공한다.
- 스킬 메타데이터 snapshot·반복 읽기 중복 제거·문맥 투영 재사용·같은 파일 대여·TUI 희소 미리보기와 닫기 시 취소를 적용한다.
- 디코딩한 명령의 처리 수명과 실제 원문 크기에 맞는 서버 메모리 예약, 동시 모델 문맥 예산, 취소 가능한 명령 출력 입장, 상세 JSON 증분 인코딩으로 불필요한 보관·재계산을 줄인다.
- 도구 출력의 문자열·JSON 저장 원본을 공유하고 호출 묶음의 journal 커밋을 합친다.
- Task의 code·persistence를 제공한다. 완료 저장을 읽기로 확인하고 불확실하면 새 접수를 막으며, 도구 효과나 내부 실패를 자동 재생하지 않는다.

- native 접수와 완료를 프로젝트별 SQLite 트랜잭션으로 확정하고 같은 키의 중복 실행을 차단한다.
- 선택한 대화와 실행 중인 작업의 소유권을 구분하고, 취소·종료 시 모델 연결·조회 작업·명령 출력 자료를 정리한다. 모델 교체 결과가 불확실하면 기존 연결을 계속 사용하지 않는다.
- 세션 저장의 중복 식별자·인덱스와 반복 조회를 줄이고, 준비한 기록을 함께 저장한다. 팀 공개 문맥은 확정한 원본과 출처를 기준으로 복원한다.
- 서버 입력·조회·출력과 SQLite 연결·저장 용량을 제한하고, 긴 응답·셸 출력·TUI Markdown에서 불필요한 복사와 보관을 줄인다.

## 실행과 보관

기본 `meca`는 TUI다. `--print`는 최종 답변, `--mode json`은 순서 있는 이벤트를 출력한다. 서버는 TTY 없이 작업을 소유하며 관찰 연결 종료만으로 작업을 취소하지 않는다. 자체 API는 task ID와 승인 ID를 연결한 일회성 결정 채널을 제공한다.

세션 DB는 schema 28을 사용한다. 미지원 DB는 목록에 사용 불가 사유를 표시하고 열기·내보내기를 거부하며 새 대화 시작은 유지한다. 서버 접수 DB는 user_version 4으로 프로젝트별 SQLite에 저장하며 이전 SQLite 형식도 자동 변환하지 않는다. 이전 JSON 접수 파일이 있으면 원본을 보존하고 서버 시작을 거부한다. 자동 변환·삭제·재실행은 하지 않는다. 기본 프롬프트는 `~/.meca/prompts/single/`과 `team/`에 보관하며 install·upgrade는 배포 기본본으로 갱신한다. 대화 백업에는 사용자 DB와 팀 개인 DB, 자격 증명 백업에는 `credentials.db`와 OS 키 저장소를 함께 포함한다.
