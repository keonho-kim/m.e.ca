# M.E.CA v0.0.20261123

- **팀 규모와 초대.** 고정 8명 상한을 없앴습니다. 팀원은 동료의 담당 업무와 명령 상태를 확인하고, 바로 맡을 동료가 없는 독립 작업에 한 명을 초대합니다. 공용 작업 키 `domain`과 제안 순번 `work_ref`를 재사용해 중복 초대를 막고, 실행 예산과 가용 메모리에 맞춰 참여 규모를 조절합니다. [팀 모드 시작과 참여](https://github.com/keonho-kim/m.e.ca/blob/v0.0.20261123/docs/team.md#시작과-참여)
- **팀 요약과 공용 기록.** 팀 요약은 최대 256KiB로 확대하고 모델 호출에 필요할 때만 조립합니다. 공용 기록은 텍스트와 이미지가 16MiB 수신 예산을 공유하는 배치로 읽습니다. 유휴 팀원은 이전 요약을 해제합니다. [팀 자원 관리](https://github.com/keonho-kim/m.e.ca/blob/v0.0.20261123/docs/team.md#자원-관리)
- **팀 실행 안정성.** 서로 독립적인 초대의 세션 준비를 겹쳐 진행하고 합류 직전에 최신 작업 담당을 확인합니다. 초대에 잠시 예약된 모델 호출 때문에 기존 팀원이 조기 종료되는 문제를 고쳤습니다. 오래된 파일 변경 기록이 정리된 뒤 작업을 재개하는 팀원은 편집 전에 현재 파일을 다시 확인합니다. [팀 자원 관리](https://github.com/keonho-kim/m.e.ca/blob/v0.0.20261123/docs/team.md#자원-관리)
- **서버 초안 메모리.** 원문과 미리보기에 프로세스 전체 16MiB 메모리 예산을 적용합니다. 저장 이력과 일치하는 메모리 초안은 버퍼를 해제하고 같은 초안의 원문 페이지를 저장 이력에서 이어 읽습니다. 큰 원문은 용량 한도가 있는 비공개 임시 파일에서 페이지로 조회합니다. [서버 이벤트와 원문 조회](https://github.com/keonho-kim/m.e.ca/blob/v0.0.20261123/docs/server.md#이벤트재접속수명)
