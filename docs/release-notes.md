macOS · Linux / amd64 · arm64

### LAT 독립 검토

- `!lat`로 Look at This를 켜고 끕니다. 기본은 OFF이며, ON은 하단 모델 행에 표시합니다.
- 같은 메인 실행 엔진으로 읽기 전용 계획·사전 검토·계획 보완을 수행한 뒤 구현하고, 최종 답변 전에 읽기 전용으로 한 번 검토합니다. 각 단계는 필요한 소스를 읽고 검색하며 요청당 한 번만 시작합니다. 메인이 필요한 보완을 수행하고 종료하며 재심사나 통과 조건을 두지 않습니다.
- 검토에는 현재 요청·독립 LAT 메모·이후 사용자 지시와 실제 결과·답변 초안을 전달합니다. 메인의 압축 메모·답변 이력·Thinking은 검토 근거에 포함하지 않습니다.
- 자료가 쌓이면 LAT 전용 메모를 백그라운드에서 압축합니다. 최신 지시·결과는 원문 증분으로 이어받고, 실패·취소 시 이전 메모와 원본을 보존합니다. 비활성 상태에서는 일반 메인 루프에 추가 호출·자료 조회·요약 작업이 없습니다.
- LAT의 Thinking·응답·도구 호출·결과를 스트리밍하고, 본문 너비의 `Look At This` 제목 구분선과 종료 가로선으로 구분합니다. 상단의 `Running Look At This` 점은 1·2·3개로 순환하며 Compaction과 타이머를 공유합니다.
- 별도 단계의 도구 이력·Thinking·응답은 같은 세션 DB의 내부 기록에서 화면으로 복원하고 메인 문맥에는 완성된 계획·검토 의견을 전달합니다. 읽기 전용 단계는 빌드·테스트·네트워크를 실행하지 않습니다.
- 별도 단계와 LAT 메모 압축의 실제 토큰·OpenRouter 보고 비용은 작업·세션 통계에 포함하고 메인 Compaction 발동량과 분리합니다. 검토 중 방향 수정과 사용자 중지를 지원합니다.

[LAT 사용법과 비용](https://github.com/keonho-kim/m.e.ca/blob/main/docs/usage.md#lat-독립-검토)

### 메모리와 응답 처리

- 파일 원본·버전·해시를 한 번에 캡처하고 독립 파일의 후보 준비를 크기에 따라 최대 4개씩 처리합니다. 승인·실행 직전 검사·결과 저장은 순서를 유지하고, 실행 버전 검사는 스트리밍으로 수행합니다.
- 파일 묶음·재귀 폴더 계획에서 중복 루트 검사를 줄이고, 승인 후와 실행 직전에는 경로·원본을 다시 확인합니다.
- 같은 이력 페이지에서 반복되는 본문은 최대 2MiB의 임시 캐시로 복원하고, LAT는 전체 원본을 인증한 발췌를 최대 256KiB까지 재사용합니다. 참조 인덱스도 256개로 제한하며 예산을 넘는 원본은 캐시 없이 읽습니다. 마지막 참조 또는 페이지 종료 시 해제하고 다음 조회에서 다시 검사합니다.
- 압축 전처리의 중복 해시와 LAT 자료의 반복 JSON 해석을 줄입니다. 사용자 지시·시간순 자료·기존 모델 호출 범위를 유지합니다.
- 긴 일반 Markdown 완료 응답과 파일 미리보기는 독립 블록을 최대 네 그룹으로 처리합니다. 최상위에 표가 있는 문서는 임시 메모리를 줄이도록 직렬 처리합니다. 활성 응답은 증분 렌더링을 유지하고 모든 표시 결과에 같은 캐시 예산을 적용합니다.
- 세션 목록은 작은 목록에 읽기 작업자 하나를 사용하고 16개 이상이면 최대 두 개로 조회합니다. 파일 대기열을 제한하고 조회·오류·취소 후 연결과 작업자를 정리합니다.
- 긴 문단은 ASCII 줄 바꿈과 줄 내부 희소 위치를 사용하고, 열린 코드 펜스는 완성된 줄을 재사용합니다. 한글·이모지와 Markdown 의미·복사 좌표를 보존합니다.
- Thinking·응답·가시 이력의 표시 캐시는 합산 16MiB 예산을 사용합니다. LAT 그룹 식별자는 단계 수명 동안 재사용합니다.
- LAT 화면 이력은 중첩 필드를 한 번에 복원하고, 공통 근거는 저장 비용이 유리할 때 기존 payload에서 공유합니다. 원래 native 입력을 정확히 복원하며 같은 본문 전체의 압축이 더 작으면 그 방식을 사용합니다.
- 압축본과 문맥 점유 표본은 최신 한 건을 교체 저장하고 실제 사용량·원본 대화·도구 결과를 보존합니다.
- LAT 자료는 이미 스캔한 순번부터 조회하고, 변화 없는 도구 결과는 파일 상태를 재구성하지 않습니다. 명령 로그는 실행 중과 완료 후 같은 경로를 사용합니다.
- LAT 입력 봉투·공통 지침·도구 스냅샷을 재사용하고 이미지 크기 판정의 전체 직렬화를 제거합니다. 사전 세 단계의 근거를 한 사본으로 공유하고 읽기 전용 조회를 기존 제한 안에서 병렬 실행합니다. 단계 중간 상태 생성·Thinking 중복 저장을 줄이고 완료 명령의 문맥을 즉시 해제합니다.
- 긴 Markdown 목록과 변경되지 않은 대화 이력의 배치를 재사용합니다. 화면 밖 파싱 결과와 큰 완료 응답의 표시 캐시를 해제하고, 입력·스크롤과 스트리밍 순서를 유지합니다.
- native 호출·이미지 이력과 도구 스키마의 최종 전송 조각을 재사용해 반복 인코딩과 대용량 복사를 줄입니다. 문맥은 변경된 native 그룹만 재검사하고 메시지 배열을 한 번 할당합니다. 설정·도구 정의·전체 모델 문맥은 계속 전송하며 재시도·리다이렉트는 같은 본문을 다시 읽습니다.
- LAT 자료는 입력 예산 안에서 선택합니다. 큰 출력·diff는 전체 길이·해시를 확인하면서 필요한 발췌만 메모리에 보관합니다.
- 실행 체크포인트와 독립 메모는 각각 최신 상태를 저장합니다. 화면 이력은 표시할 필드만 복원하고 원본 대화·실행 결과는 내보내기에 보존합니다.
- 캐시·요약 작업·출력 캡처는 완료·오류·취소 시 정리합니다.

### 명령 실행과 출력

- 시간 만료와 정리용 취소가 겹쳐도 명령의 timeout 상태와 원래 만료 사유를 보존합니다.
- 명령 완료 알림으로 결과를 수집하고, 출력이 바뀐 스트림만 복사·마스킹합니다. 모델의 매 응답 조각마다 명령 상태와 LAT 자료를 다시 조회하지 않습니다.
- 큰 활성 출력은 임시 키로 암호화한 제한 크기 파일에 보관합니다. stdout·stderr는 각각 앞뒤 합계 16MiB까지 수집하며 생략 여부와 재조회 경로를 제공합니다.
- 명령은 병렬로 실행하고 준비된 결과는 호출 순서대로 저장·표시합니다. 전체 캡처는 저장할 차례에 읽고 DB 커밋 후 해제합니다.

### 코드 구성과 수명 관리

- 대화 표시·입력과 예약·파일 탐색·모델 연결·작업 시계가 각각 상태와 전이를 소유합니다. 변경 가능한 화면 상태는 하나의 이벤트 루프에서 갱신합니다.
- 입력·키맵·렌더링은 같은 포커스 판정을 사용합니다. 파일 미리보기를 닫으면 작성 중인 입력을 복원하고, 승인 화면의 Esc는 거절 처리 후 이전 화면으로 돌아갑니다.
- 메인 요청의 준비·대화 진입·결정 반복·종료 정리를 나눕니다. LAT 상태·단계 입력·읽기 전용 실행 구성을 분리하고, 종료 시 소유한 작업을 합류한 뒤 생성기 자원을 해제합니다.
- 파일·폴더·셸·명령 제어·이미지 실행은 필요한 상태와 실행 직전 검사를 각각 소유합니다. 승인과 일회 실행 진입은 공통 계약을 사용합니다.
- SQLite 조회·본문 복원과 순수 이력 표시·LAT 발췌 표현을 분리합니다. 저장 형식과 원본 복원·무결성 검사는 유지합니다.
- 화면 인덱스 구성·가시 줄 추출·Markdown 캐시 수명 관리를 분리합니다. 증분 렌더링·복사 좌표·공유 캐시 예산을 유지합니다.

### 검증

- 파일·폴더의 교체와 심볼릭 링크 변경, 후보 준비 실패·취소, 페이지별 복원의 무결성·메모리 한도와 Markdown 출력 일관성을 회귀 검사합니다.
- 화면·입력 테스트는 가상 터미널을 사용하고, 저장·복원·실행 테스트만 DB와 실제 도구를 준비합니다.
- 파일 미리보기의 키 입력·키맵 일치와 승인 거절 후 화면·작업 상태 복원을 검사합니다.
- CLI 통합 검사는 실행 파일 하나를 재사용하며 각 실행의 HOME·프로젝트·모의 서버를 분리합니다. 패키지 종료 시 빌드 산출물을 정리합니다.
- 응답·실패·취소·배치 실행 검사는 책임별로 구성합니다. 성능 검사의 재현 명령과 측정 기준은 개발 가이드에서 확인할 수 있습니다.

### 설정과 설치

- 기본 프롬프트는 `system.md`, `development.md`, `compaction.md`, `lat.md`, `lat_plan.md`, `lat_critique.md`, `lat_refine.md`, `lat_compaction.md`입니다. 계획·계획 보완은 `[agent]`, 사전·최종 검토는 `[lat]`, 독립 메모 압축은 `[lat_compaction]`에서 추론 인자를 지정합니다.
- 세션 저장 형식은 **schema 23**입니다. 지원하지 않는 DB는 변환·삭제 없이 원본을 보존하고 오류를 반환합니다.
- 운영체제와 CPU에 맞는 아카이브를 받아 압축을 풀고 `./meca install`을 실행합니다. 업데이트는 `meca upgrade`를 사용하며 기본 프롬프트를 배포본으로 갱신합니다.
- 명시적 외부 전송은 All Mighty에서도 매번 직접 승인받습니다.
