# M.E.CA v0.0.20261113

WebUI의 다중 탭 연결, 입력·표시 성능과 원문 탐색을 보강한 릴리즈입니다.

## 연결과 복구

- 작업·파일 관찰을 페이지당 하나의 쿠키 인증 WebSocket으로 통합해 HTTP/1 다중 탭의 일반 API 정체를 해결했습니다.
- 페이지 복원 시 인증과 snapshot을 다시 확인하고, 제한된 전송 배치·ACK와 분산 재접속을 적용했습니다.
- 인증 만료 시 민감한 폼·조회 캐시·진행 중 읽기를 정리하며 미전송 입력과 편집 초안을 보호합니다.
- 지연 로딩 실패를 독립된 복구 화면에서 처리하고, UI 빌드 식별·미저장 파일 내려받기·재로드 안내를 제공합니다.

## 화면·입력·성능

- Astryx Core·Neutral·CLI를 0.7.14로 갱신했습니다.
- 도구 요청 원문을 결과 아코디언 안의 접힌 영역으로 옮겼습니다. 큰 도구 결과는 필드별 페이지로 읽을 수 있습니다.
- 숨긴 채팅 본문을 동결하고 Markdown 증분 파싱과 문자 표시 효과를 분리했습니다. AST·코드 페이지 계산과 큰 요청 인코딩도 보강했습니다.
- 일반 타이핑은 편집 범위의 UTF-8 바이트 증감을 계산하며, 큰 입력 검사는 나누어 처리하고 큰 JSON 전송은 Worker에서 준비합니다.
- 첨부 미리보기에 픽셀 예산과 파생 썸네일을 적용하고 원본·디코딩·표시 URL의 수명을 분리했습니다. 애니메이션 WebP의 대표 프레임 검증도 보강했습니다.
- 가상화한 채팅·파일 목록의 포커스와 드래그 행을 보존하고, 폼 오류 포커스·화면 제목·대화 링크·스트리밍 접근성을 개선했습니다.
- 파일 이동 메뉴와 저장된 메시지·추론 검색을 추가했습니다.

## API와 보안

- 자체 API에 `searchHistory`, `detail.field`·`detail.listFields`와 이미지 픽셀·미리보기 한도를 추가했습니다.
- 내장 UI에 관찰·임시 썸네일 API를 제공하고, 읽기 요청 마감과 페이지 복원 시 재동기화를 보강했습니다.
- favicon 등 고정 URL 자산의 캐시 정책을 재검증 방식으로 바꾸고 UI 보안 헤더를 보강했습니다. Trusted Types는 보고 전용으로 적용합니다.

외부 클라이언트는 새 조회 기능을 사용할 때 갱신된 `api/meca/v1/*.proto`와 [API 계약](https://github.com/keonho-kim/m.e.ca/blob/main/docs/server.md)을 확인하세요.
