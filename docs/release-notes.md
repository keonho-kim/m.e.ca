# M.E.CA v0.0.20261117

WebUI의 시작 화면과 스트리밍·스크롤 동작을 개선하고 Astryx를 갱신한 릴리즈입니다.

## 대화와 입력

- 작업공간 선택 전·새 대화 생성 전·빈 대화의 시작 화면을 통일했습니다. 작업공간을 선택하면 바로 입력할 수 있고 첫 전송 시 대화를 생성합니다. 미선택 상태에서는 입력을 비활성화합니다.
- 대화 생성 실패 시 초안·이미지를 보존하고, 생성 도중 작업공간을 바꾼 경우 이전 입력을 전송하거나 화면을 되돌리지 않습니다. 미저장 파일이 있을 때의 이동도 보호합니다.
- 빈 대화의 검색 버튼과 Thinking 밖의 중복 실행 표시를 제거했습니다. 검색은 저장된 내용이 있는 대화에서 제공합니다.
- 중단·실패 후 통계 옆의 상세 보기 버튼을 제거했습니다. 중단·실패 상태와 토큰 사용량, 속도, 소요시간은 계속 표시합니다.
- 설정 드롭다운·모델 목록을 라이트·다크 모두 불투명하게 표시합니다.

- 컴포저의 `#` 스킬 후보 목록에서 불필요한 가로 스크롤을 방지하고, 세로 목록의 높이와 스크롤 표시를 제한했습니다.

## 스트리밍과 승인

- Steer 입력의 저장 메시지와 실시간 이벤트를 같은 식별자로 연결해 중복 표시와 남아 있는 실시간 항목을 정리했습니다. 같은 문구를 다시 보낸 별도 입력은 유지합니다.
- 추론·답변·도구·스킬 알림이 저장 이력으로 전환되거나 재접속하더라도 표시 순서를 유지합니다. 팀 답변과 작업 중 추가한 사용자 입력도 해당 순서에 포함합니다.
- 거절·실패한 도구 호출의 실시간 결과와 저장 결과가 중복 표시되지 않도록 고유 식별자를 부여했습니다. 모델 재시도와 마스킹 갱신 시 이전 초안도 정리합니다.
- 자동 스크롤과 가상 이력의 높이 보정이 충돌해 추론 중 따라가기가 멈추는 문제를 수정했습니다. 사용자가 이전 내용을 읽거나 탐색할 때는 위치와 포커스를 유지합니다.
- 승인 모달은 작업명·짧은 대상·승인 사유를 먼저 표시합니다. 상세 명령·diff는 원문 보기를 눌렀을 때 조회합니다.
- 현재 대화의 승인 상태를 본문·조회 캐시에서 분리해 오래된 조회 응답이나 이력 정리가 승인 모달을 숨기지 않도록 보강했습니다.
- 자체 API에 `Draft.startSequence`, `Approval.reasons`, `Event`·`Draft`·`HistoryItem`의 `presentation` 식별자를 추가했습니다. 갱신된 [API 계약](https://github.com/keonho-kim/m.e.ca/blob/main/docs/webui-api.md)을 참고하세요.

## 의존성과 개발

- Astryx Core·Neutral·CLI를 0.7.16으로 갱신해 컴포저·메뉴·이미지 상호작용 수정을 반영했습니다. 빈 컴포저 높이 우회 코드를 제거했습니다.
- 새 Astryx 상태 관리에 맞춰 Markdown 문자 표시·유휴 프레임 중단 패치를 재구성하고 스크롤 패치를 유지했습니다. 배포 라이선스 고지도 갱신했습니다.
- 대화 생성·재접속 순서·승인·스크롤의 회귀 검사를 보강했습니다.
