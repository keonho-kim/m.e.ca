운영체제와 CPU에 맞는 아카이브와 `checksums.txt`를 내려받아 SHA-256을 확인한 뒤 압축을 풀고 `./meca install`을 실행하세요. 릴리스 바이너리는 Go 설치가 필요하지 않습니다.
