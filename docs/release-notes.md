# M.E.CA v0.0.20261118

- `browser_inspect`의 텍스트 관찰을 한 번씩 순서대로 읽습니다. 첫 페이지는 기본 2KiB, 다음 페이지는 기본 8KiB입니다. 더 읽으려면 가장 최근 결과의 `next_offset`을 사용합니다. 같은 페이지를 동시에 요청해도 한 번만 반환하며, 마지막 페이지를 읽으면 임시 파일을 삭제합니다.
- 모델 응답이 성공하면 읽은 페이지 본문을 실행 메모리에서 비웁니다. 다음 모델 요청과 대화 요약에는 본문이 반복해서 들어가지 않으며, 대화 기록에서는 원래 도구 결과를 확인할 수 있습니다.
- Provider가 모델 요청을 생성 전에 문맥 초과로 거절하면 이전 이력을 압축합니다. 아직 읽지 않은 브라우저 페이지와 해당 도구 호출을 보존하고, 원래 출력 설정으로 작업을 이어갑니다.
- `meca install --ext browser`로 브라우저 도구를 미리 준비하고 점검할 수 있습니다. 전용 빈 페이지 열기·스냅샷 읽기·종료가 성공하면 도우미와 브라우저의 실행 경로를 표시합니다. Linux에서 필요한 공유 라이브러리가 누락된 경우 라이브러리 이름을 안내합니다.
- 솔로·팀 에이전트의 브라우저 도구 설명에 system 범위와 동작별 승인 조건을 명시했습니다. 열린 페이지가 없는 상태에서 클릭이나 입력을 요청하면 승인 창을 띄우기 전에 오류를 반환합니다.
