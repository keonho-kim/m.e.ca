### 파일 탐색과 Markdown 뷰어

- !dir의 분할·전체화면 뷰어에서 Markdown을 렌더링하고 Shift+R로 Raw 원문과 전환합니다. 전환 동작을 하단 키맵에 표시하며 Mermaid는 코드 블록으로 보여줍니다.
- 작업 중에도 !dir에서 파일을 탐색·선택하고 미리볼 수 있습니다. 미리보기를 닫아도 진행 중인 작업과 작성한 입력은 유지됩니다.
- Shift+Tab으로 파일 목록과 입력창 사이를 이동합니다. 작업 중 입력창의 Enter는 방향 수정, Tab은 후속 요청 예약을 확인합니다. y·Y로 전송하고 N·Esc로 입력을 보존합니다. 선택 경로는 요청과 함께 전달되고 대화에 저장됩니다.
- 보기 전환은 읽어 둔 파일 내용을 재사용합니다. 파일 변경으로 미리보기가 갱신되면 표시 모드와 읽기 위치를 유지합니다.

### 명령 실행 표시 개선

- execute_command는 최대 30초까지 기다린 뒤 실행 중이면 running을 반환합니다. 결과에는 wait_command·cancel_command·list_command_runs로 같은 명령을 관리하는 안내를 포함합니다. 명령은 계속 실행됩니다.
- 병렬 실행 중인 명령을 각각 표시하며, 한 명령의 완료가 다른 명령의 진행 표시를 지우지 않습니다.
- 긴 명령은 실행 중에도 줄바꿈해 전체를 표시합니다. 화면을 넘는 내용은 스크롤로 확인할 수 있습니다.
- 병렬 결과는 원래 호출 순서대로 준비된 구간부터 저장·표시하며, 나머지 명령 전체의 종료까지 기다리지 않습니다.
- 경과 시간과 실제 stdout·stderr의 마지막 수신 이후 시간을 구분합니다. 출력이 없으면 ‘아직 출력 없음’을 표시합니다.

### 설치와 업데이트

운영체제와 CPU에 맞는 `.tar.gz` 파일을 내려받아 압축을 풀고, 압축을 푼 폴더에서 `./meca install`을 실행하세요. 릴리스 바이너리는 Go 설치가 필요하지 않습니다. 체크섬 확인·소스 빌드 등 상세 절차는 README의 접는 설치 안내에서 확인할 수 있습니다.

설치 후 `meca`로 시작하고 `!model`에서 모델을 연결하세요. 업데이트는 실행 중인 MECA를 종료한 뒤 `meca upgrade`로 진행합니다. 설정·대화는 유지하며 프롬프트는 배포 기본본으로 갱신합니다.

명시적 외부 전송은 All Mighty에서도 매번 직접 승인받습니다. 설정 저장·파일 전송 확인에서는 `y`·`Y`로 진행하고 대문자 `N`으로 취소합니다. 소문자 `n`은 무시합니다. 오래 실행되는 명령은 내부 ID로 조회·대기·취소하며 최종 답변 전에 종료 결과를 수집합니다.
