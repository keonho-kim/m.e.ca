# M.E.CA v0.0.20261118

- 브라우저 관찰은 첫 페이지 기본 2KiB, 다음 페이지 기본 8KiB로 순서대로 읽습니다. 모델이 읽은 페이지와 스크린샷은 다음 요청의 문맥에서 제거하고, 대화 기록에는 원본을 보존합니다. 다 읽은 임시 파일 블록은 바로 회수합니다.
- Provider가 생성 전에 문맥 부족을 보고하면 이전 이력을 압축합니다. 아직 읽지 않은 관찰과 이를 요청한 도구 호출을 보존하며, 다른 도구를 거친 뒤에도 브라우저가 제공하는 최신 커서로 이어 읽을 수 있습니다.
- 변경되지 않은 스냅샷은 도우미에서 본문 전송을 생략합니다. 텍스트·오류·스크린샷을 현재 URL 확인과 함께 가져오며, 새 관찰 앞의 대화 이력은 인코딩을 재사용합니다.
- `meca install --ext browser`로 브라우저 도구를 미리 준비하고 점검할 수 있습니다. 전용 빈 페이지 열기·스냅샷 읽기·종료가 성공하면 도우미와 브라우저의 실행 경로를 표시합니다. Linux에서 필요한 공유 라이브러리가 누락된 경우 라이브러리 이름을 안내합니다.
- 관리형 Chrome이 갱신되는 동안 검증된 기존 버전으로 새 세션을 열 수 있습니다. 실행 중인 버전과 직전 버전을 보존하고, 사용이 끝난 더 오래된 관리 설치본을 정리합니다. 도우미 프로세스를 시작하기 전에 실패하면 확보한 브라우저 슬롯을 반환합니다.
- 솔로·팀 에이전트의 브라우저 도구 설명에 system 범위와 동작별 승인 조건을 명시했습니다. 열린 페이지가 없는 상태에서 클릭이나 입력을 요청하면 승인 창을 띄우기 전에 오류를 반환합니다.
