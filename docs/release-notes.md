macOS · Linux / amd64 · arm64

### 이미지 읽기

- 이미지 입력이 확인된 모델에 read_image를 제공하고 !model에 지원 상태를 표시합니다.
- PNG/APNG·JPEG·WebP·GIF·BMP·TIFF를 읽으며 애니메이션·다중 페이지는 대표 정지 이미지를 전달합니다.
- OpenRouter는 메타데이터를 사용하고, 그 밖의 확인 불가 연결은 작은 PNG 요청으로 입력 수용을 검사합니다. 답변의 인식 정확도는 평가하지 않습니다.
- 이미지 본문은 세션에 보존하고 화면에는 경로·형식·해상도·대표 프레임 여부를 표시합니다. 이미지 미지원 연결에서는 도구와 이미지 입력을 제외하고 텍스트 작업을 이어갑니다.

### 성능과 복원 안정성

- 텍스트·이미지 요청을 한 번 직렬화하고 Base64를 최종 크기의 버퍼에 직접 기록해 중간 복사와 메모리 할당을 줄입니다.
- 이미지 파일은 열린 파일의 크기에 맞춘 버퍼로 읽고, 읽는 도중의 크기·파일 변경을 확인합니다. 정지 PNG의 메타데이터를 애니메이션으로 오인해 재인코딩하는 문제를 수정했습니다.
- 대화 복원은 최근 사용자 입력만 조회하고, 중단 복구는 미완료 도구 호출의 인자만 복원합니다. 부분 완료된 병렬 호출과 서로 다른 호출에서 재사용된 ID를 구분합니다.
- 텍스트 모델의 문맥을 불러올 때 이미지 본문을 복원하지 않습니다. 이미지 제외 안내를 포함한 전송 대상에 맞춰 문맥 바이트 예산을 계산합니다.
- 압축 경계는 마지막 완료 응답 이후의 미소비 이미지 그룹만 검사합니다. 중단된 응답·최신 사용자 지시·도구 결과 쌍과 원본 이미지 기록을 보존합니다.

### 파일 탐색과 요청 입력

- 작업 중에도 !dir에서 파일을 탐색·선택하고 요청을 작성합니다. Shift+Tab으로 파일 목록과 입력창 사이를 이동합니다.
- 파일 목록의 Tab은 오른쪽 분할 미리보기, Enter는 전체화면입니다. Markdown은 렌더링하고 Shift+R로 줄 번호가 있는 Raw 원문과 전환합니다. Mermaid는 코드 블록으로 표시합니다.
- 파일 읽기와 Raw/Markdown 배치는 백그라운드에서 준비하고 최신 원문·폭·모드에 맞는 결과를 표시합니다. 보기 전환은 읽어 둔 본문을 사용하며 파일 갱신은 모드와 읽기 위치를 보존합니다.
- 작업 중 입력창의 Enter는 방향 수정, Tab은 후속 요청 예약을 확인합니다. y·Y로 전송하고 N·Esc로 초안을 보존합니다. 예약에는 당시 선택한 경로를 보관하며 본문 편집·중지 후 초안 복구에도 유지합니다.
- 승인 화면에서는 승인·거절 키맵을 표시하고, 결정 후 보류한 파일 뷰어와 입력 초안으로 돌아갑니다.

### 명령 실행과 출력

- execute_command는 최대 30초까지 기다리며 완료 시 즉시 결과를 반환합니다. 실행 중이면 running·command_id와 wait_command·cancel_command·list_command_runs 사용 안내를 반환하고 명령을 계속 실행합니다.
- 병렬 명령의 진행 상태와 완료 결과를 각각 표시합니다. 준비된 결과는 호출 순서대로 저장·표시합니다.
- 긴 명령은 줄바꿈하고 화면을 넘는 내용은 스크롤로 확인합니다. 경과 시간과 stdout·stderr의 마지막 수신 이후 시간을 표시하며 출력이 없으면 ‘아직 출력 없음’으로 안내합니다.
- 출력 내용이 바뀐 스트림만 복사·마스킹해 발췌와 로그를 갱신합니다. 명령 결과 수집과 요청·실행기 종료에서 표시 캐시를 해제합니다.

### 설치와 업데이트

운영체제와 CPU에 맞는 `.tar.gz` 파일을 내려받아 압축을 풀고, 압축을 푼 폴더에서 `./meca install`을 실행하세요. 릴리스 바이너리는 Go 설치가 필요하지 않습니다. 체크섬 확인·소스 빌드 등 상세 절차는 README의 접는 설치 안내에서 확인할 수 있습니다.

설치 후 `meca`로 시작하고 `!model`에서 모델을 연결하세요. 업데이트는 실행 중인 MECA를 종료한 뒤 `meca upgrade`로 진행합니다. 설정·대화는 유지하며 프롬프트는 배포 기본본으로 갱신합니다.
