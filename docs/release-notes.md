# 자율 협업 팀 모드

macOS · Linux / amd64 · arm64

### 변경 사항

- `!team`으로 독립 세션의 자율 협업을 선택합니다. 두 에이전트가 시작하고 동시에 최대 8개 세션이 같은 프로젝트에서 작업합니다.
- 공개 응답·진행 안내와 동료 초대·기존 세션 복구·기여 보고와 종료를 팀 전용 native 도구로 제공합니다. 마지막 에이전트가 사용자에게 최종 결과를 보고합니다.
- 하나의 대화 화면에서 발신자별 공개 응답을 스트리밍하며 팀 Thinking은 개인 기록에 보관합니다. 도구 결과는 기본으로 접히며 `Ctrl+O`로 펼칩니다.
- 공유 파일 변경과 셸 실행을 조율하고 기존 승인·보호 경로·원본 검사를 적용합니다. 취소 시 모든 팀 작업을 정리합니다.
- 공용 본문·도구 이력은 원본 참조로 저장하고 개인 수신 위치를 문맥과 함께 기록합니다. 토큰·비용은 팀의 실제 보고량을 합산합니다.
- 공개 발언에는 변경 목적·파일 경로를 먼저 공유하도록 안내하며 활성 동료에게 추가 초대 지시를 전달하지 않습니다.
- 대기 중 개인 실행·문맥을 유지하고 미수신 대화가 있을 때만 재개합니다. 스트림은 증분 Markdown 상태를 재사용하고 접힌 도구 상세는 펼칠 때 조회합니다.
- 대화·도구 원본의 페이지 조회와 짧은 본문 저장을 최적화하고, 후보 준비 전 접근 예약·실패 시 DB 정리·전체 캐시 예산을 적용합니다.
- 기본 단일 요청 경로와 팀 실행 구성을 분리하고 프롬프트·문서·키 안내를 맞췄습니다.

### 업데이트 안내

- 세션 저장 형식은 **schema 26**입니다. 지원하지 않는 형식은 자동 변환·삭제하지 않으므로 새 대화를 시작해야 합니다.
- 기본 프롬프트는 `~/.meca/prompts/single/`과 `~/.meca/prompts/team/`에 각각 `system.md`·`development.md`·`compaction.md`로 생성합니다. 설치·업그레이드 시 배포 기본본으로 갱신합니다.
- 팀 대화의 개인 DB는 관련 `.team` 하위 폴더에 있습니다. 대화 보존에는 사용자 DB와 해당 폴더를 함께 포함하세요.
