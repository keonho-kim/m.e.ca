# M.E.CA

- **Code Mode 도구 실행.** 모델은 `codemode`에 JavaScript·TypeScript 본문을 전달하고 `tools.*` 호스트 함수로 작업합니다. tui·full에 변환기와 실행기가 포함되어 별도 Go·Node.js·TypeScript 설치가 필요 없습니다. [코드와 도구 계약](https://github.com/keonho-kim/m.e.ca/blob/main/docs/codemode.md)
- **반환값과 자동 전달.** 명시적인 `null`을 포함한 반환값을 그대로 사용합니다. `undefined`로 정상 종료하면 저장이 확인된 성공 결과를 합계 512KiB JSON 안에서 가능한 한 전부 전달합니다. 초과분만 실제 인코딩 크기에 맞춰 자르고 잘림을 표시합니다. 원래 작업을 다시 실행하거나 반환하지 않은 지역 계산값을 재구성하지 않습니다. [반환 누락 처리](https://github.com/keonho-kim/m.e.ca/blob/main/docs/codemode.md#반환값-누락-시-자동-전달)
- **대화 문맥과 스킬.** 시스템 지침은 사용자가 요청한 결과와 범위를 이해하도록 안내합니다. 스킬의 본문·참고 지침·이미지는 모델이 확인할 입력으로 전달하고, 작업 범위는 사용자 요청에서 결정합니다. [런타임](https://github.com/keonho-kim/m.e.ca/blob/main/docs/runtime.md) · [스킬](https://github.com/keonho-kim/m.e.ca/blob/main/docs/skills.md)
- **작업별 승인과 비동기 실행.** 실제 내부 호출의 인자·대상·셸 AST를 검사하고 필요한 작업을 승인받습니다. 독립 도구는 완료 결과를 저장한 직후 해당 Promise를 재개하며 진행 중인 작업과 충돌을 확인합니다. 승인 거부·취소·저장 실패 시 후속 실행을 중단하고 수행된 효과를 기록합니다. [승인 경계](https://github.com/keonho-kim/m.e.ca/blob/main/docs/execution-boundary.md)
- **실행 표시와 원문 보존.** TUI·WebUI는 코드 실행과 내부 작업을 연결해 표시합니다. 코드 실행 수와 실제 도구 실행 수를 구분하고, 모델용 반환·발췌와 저장 원문을 별도로 관리합니다. [출력과 저장](https://github.com/keonho-kim/m.e.ca/blob/main/docs/runtime.md#출력과-저장)
- **개발 가이드와 검색.** `#development`는 설계 패턴·알고리즘·자료구조·앱·UI·백엔드·검증 자료를 연결합니다. `meca develop "검색어"`로 필요한 참고 경로·줄 번호·절 제목을 찾고 Code Mode의 스킬 읽기 함수로 확인할 수 있습니다. [기본 스킬](https://github.com/keonho-kim/m.e.ca/blob/main/docs/builtin-skills.md) · [CLI 검색](https://github.com/keonho-kim/m.e.ca/blob/main/docs/cli.md#개발-자료-검색)
- **설치와 기본 자료 갱신.** `meca install`·`meca upgrade`는 배포 기본 프롬프트와 스킬 파일을 현재 배포 내용으로 갱신합니다. 사용자 추가 자료는 보존하며, 일반 시작은 누락된 배포 파일만 생성합니다. [설치와 갱신](https://github.com/keonho-kim/m.e.ca/blob/main/docs/cli.md#설치업데이트삭제)
- **로컬 저장과 운영.** API Key는 로컬 키 저장소를 사용하는 암호화 DB에 보관합니다. 컨테이너의 마운트·권한 오류는 대상과 복구 방법을 알리며, 서버는 작업 실행과 관찰 연결의 수명을 구분합니다. [설정과 보존](https://github.com/keonho-kim/m.e.ca/blob/main/docs/configuration.md) · [서버](https://github.com/keonho-kim/m.e.ca/blob/main/docs/server.md)
