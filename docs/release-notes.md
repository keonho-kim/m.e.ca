# 자율 협업 팀 모드

macOS · Linux / amd64 · arm64

### 변경 사항

- `!team`으로 자율 협업을 선택하면 다음 요청부터 두 독립 세션이 시작합니다. 동시에 최대 8개 세션이 같은 프로젝트에서 작업합니다.
- 필요한 미완료 작업의 범위·선행 조건이 명확하고 추가 인원이 병렬 진행에 도움이 될 때 동료를 초대하거나 이전 세션을 복구합니다. 마지막 에이전트가 사용자에게 최종 결과를 보고합니다.
- 하나의 대화 화면에서 발신자별 공개 응답을 스트리밍하며 팀 Thinking은 개인 기록에 보관합니다. 도구 결과는 기본으로 접히며 `Ctrl+O`로 펼칩니다.
- 파일별 담당 범위를 공유하고 충돌하는 변경을 조율합니다. 셸 실행은 팀 전체에서 한 번에 하나씩 진행하며 승인·보호 경로·원본 검사를 적용합니다. 취소 시 모든 팀 작업을 정리합니다.
- 공용 본문·도구 이력은 원본 참조로 저장하고 개인 수신 위치를 문맥과 함께 기록합니다. 토큰·비용은 팀의 실제 보고량을 합산합니다.
- 이름을 부르는 공개 질문·답변·반론과 함께 작업 목적·대상 경로·인터페이스를 공유합니다. 미검토 관련 피드백이 있으면 퇴장 전에 확인합니다.
- 대기 중 개인 문맥을 유지하고 사용자 지시·관련 토론·변경 등 주의가 필요한 새 사실을 다음 판단에 반영합니다. 전체 대기가 진전 없이 반복되면 정체를 알리고 종료합니다.
- 단일 모드의 공통 시스템 지침 전체에 팀 협업 지침을 덧붙여 제공합니다. 개발·압축 기본 지침도 같은 원문을 사용합니다.

### 업데이트 안내

- 세션 저장 형식은 **schema 26**입니다. 지원하지 않는 형식은 자동 변환·삭제하지 않으므로 새 대화를 시작해야 합니다.
- 기본 프롬프트는 `~/.meca/prompts/single/`과 `~/.meca/prompts/team/`에 각각 `system.md`·`development.md`·`compaction.md`로 생성합니다. 설치·업그레이드 시 배포 기본본으로 갱신합니다.
- 팀 개인 DB는 `~/.meca/sessions/<프로젝트 키>/.team/<사용자 세션 ID>/` 아래에 있습니다. 대화 보존에는 사용자 DB와 해당 하위 폴더를 함께 포함하세요. [전체 저장 구조](https://github.com/keonho-kim/m.e.ca/blob/main/docs/team.md#프롬프트와-저장)를 참고하세요.
