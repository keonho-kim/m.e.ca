## 화면 언어

화면 문구는 시작할 때 시스템 로캘을 한 번 선택해 한국어·영어로 표시한다. LC_ALL → LC_MESSAGES → LANG 순으로 메시지 로캘을 정한다. C·POSIX는 영어이며, 그 외 로캘에서는 GNU LANGUAGE의 지원 언어 우선순위도 적용한다. 환경 변수가 없으면 macOS는 AppleLanguages의 첫 언어를 확인한다. 지원하지 않는 언어·조회 실패는 영어로 표시한다. 별도 언어 설정 항목이나 저장값은 추가하지 않는다.

한국어를 지정하려면 `LC_MESSAGES=ko_KR.UTF-8 v`로 실행한다. LC_ALL이 이미 설정되어 있으면 그 값이 LC_MESSAGES보다 우선한다. 메뉴·상태·키 안내·도구 표시·승인 사유가 같은 언어를 따르고, 명령 설명을 검색할 때도 표시된 언어를 사용한다. `allow-all`·`approve`는 화면에서 `자동 승인`·`승인 필요`로 표시하며 config.toml과 저장 기록은 원래 값을 유지한다.

사용자 입력·에이전트 응답·모델/공급자 이름·명령·경로·diff·표준 출력·외부 진단 원문은 번역하지 않는다. 응답 언어는 기존 사용자 언어 지침을 따른다.

## 시작과 모델 연결

설치·삭제 명령은 [README](../README.md#직접-빌드하기)를 따른다. 첫 실행은 ~/.v의 누락된 기본 파일을 준비한다. 일반 시작은 현재 프로젝트의 대화 목록을 표시하고 맨 위의 새 대화를 선택한다. v resume은 모든 프로젝트를 표시한다.

!model에서 Provider·주소·필요한 API Key와 모델을 선택한다. 지원 Provider는 Ollama, vLLM, SGLang, LM Studio, LiteLLM과 일반 OpenAI 호환 서버다. 주소 입력의 Ctrl+U는 전체 내용을 지우며, HTTP 어댑터가 필요한 API 경로를 조립한다. 목록 조회를 지원하지 않는 서버에는 모델 ID를 직접 입력할 수 있다.

모델 ID 입력 아래의 후보는 대소문자를 구분하지 않는 부분일치로 검색한다. ↑↓로 선택하고 Enter 또는 Tab으로 ID를 채운 뒤 Enter를 한 번 더 눌러 연결한다. 일치 후보가 없어도 직접 입력으로 연결할 수 있다. Esc는 후보를 먼저 닫고 다시 누르면 설정 화면을 나간다. 검색 중에는 이미 받은 목록을 사용한다.

서빙 별칭 오른쪽에는 확인된 단일 원본 모델명을 흐리게 표시한다. !model → 모델 정보에서 식별 근거·프로파일·서버 한도를 확인한다. 임의 별칭의 정확한 매핑과 Provider별 Thinking 계약은 [모델 프로파일](model-profiles.md)을 따른다.

연결 설정은 모델 응답 생성을 요구하지 않는다. !model → 연결 진단 또는 v --diagnose에서 일반 응답과 Thinking을 명시적으로 확인한다. 실제 작업에는 native tool calling과 서버에 맞는 parser 설정이 별도로 필요하다. 연결 진단 성공이 도구 실행 성공을 보장하지 않는다. 연결·저장 실패나 취소 시 기존 선택을 유지한다.

API Key는 macOS Keychain 또는 Linux Secret Service에 저장한다. 사용할 수 없거나 잠겨 있으면 오류를 표시하며 평문 파일로 대체하지 않는다. 인증 없는 로컬 서버는 Key를 비워 둔다. 마지막으로 선택한 연결은 새 세션에서 재사용하고, 기존 대화에서는 저장된 선택을 우선한다.

## Thinking

기본은 꺼짐이다. 한국어 !model 메뉴는 `추론 켜짐 / 꺼짐` 한 행에서 선택값을 굵게 표시한다. ←는 켜짐, →는 꺼짐이며 Enter로 적용 위치를 선택한다. 지원하지 않는 제어는 `사용 불가`로 표시한다. 영어 UI는 Thinking ON / OFF와 unavailable을 사용한다.

Thinking effort에는 해당 모델·서버에서 확인한 값만 나타난다. DEFAULT는 명시적인 강도 미지정이다. 강도 선택만으로 Thinking을 켜지 않으며 OFF에서도 선호값은 보존한다. 켜짐일 때 하단에 `추론` 또는 `추론 MEDIUM`처럼 표시하고 꺼짐에서는 생략한다. 제공자가 정의한 강도 식별값은 유지한다.

## 내부 명령과 키보드

| 입력 | 동작 |
| --- | --- |
| !model | 연결·모델·Thinking 설정 |
| !dir [path] | 파일 탐색과 참조 선택 |
| !permission | 승인 정책과 세션/전역 적용 선택 |
| !new | 현재 자원을 정리하고 같은 프로젝트에서 새 대화 시작 |
| !quit, 선택 없는 Ctrl+C | 작업·자원을 정리하고 앱 종료 |
| ! 뒤의 글자 | 명령 이름·설명을 부분일치 검색 |
| 명령 후보 ↑↓ / Enter / Tab | 이동 / 즉시 실행 / 입력만 |
| Enter / Shift+Enter | 전송 / 줄바꿈; 입력창은 기본 최대 5행 |
| 입력창 ↑↓ | 표시 줄 사이 커서 이동 |
| Ctrl/Cmd+↑↓ | 이전 입력과 작성 중 초안 탐색 |
| 작업 중 일반 입력의 Enter | 안전한 응답·도구 경계에서 방향 수정 전달 |
| 작업 중 일반 입력의 Tab | 현재 작업 뒤에 실행할 메시지 한 건 예약 |
| Ctrl+O | 도구 결과 전체 접기·펼치기; 기본 펼침 |
| Esc | 전경 UI 닫기; 전경 UI가 없으면 현재 작업 중지 |
| PgUp/PgDn, 마우스 휠 | 출력 스크롤 |
| F1 | 현재 화면의 전체 키 안내; Esc/F1로 닫기 |
| :q + Enter | 기능 화면 복귀 또는 세션 종료 |

명령 후보는 첫 명령 토큰을 편집할 때만 나타난다. 자연어 본문·인자·붙여넣기는 명령 실행으로 해석하지 않는다. 후보가 열려 있으면 ↑↓·Tab·Esc는 후보 조작이 우선이다. !dir 탐색 포커스에서도 :q를 직접 입력하고 Backspace로 수정할 수 있다.

키맵은 현재 화면·포커스·대상·작업 상태에서 가능한 동작만 보여준다. 하단 키맵과 F1 안내는 같은 키 순서를 사용한다. 폭이 부족하면 항목 전체를 생략하며 F1에서 전체 안내를 확인할 수 있다. 후속 요청이 이미 예약되면 Tab 예약 안내를 숨기고, 중지 처리 중에는 방향 수정·예약·중지 안내를 숨긴다. Ctrl/Cmd+↑↓, Shift+Enter, Cmd+C는 터미널이 해당 키를 앱에 전달해야 한다. 터미널 설정을 자동 변경하지 않는다.

## 화면과 사용량

대화는 > 사용자 입력, 빈 줄, 에이전트 응답 순서로 누적하며 다음 요청 앞에 두 줄 여백을 둔다. 입력창은 하단 모델 상태 바로 위에 고정하고 여러 줄이면 위로 확장한다. 모델·활성 추론·자동 승인 상태는 키맵 윗줄, 키맵은 마지막 줄이다. 고정 Scope는 생략하며 approve의 기본 승인 문구는 숨기고 allow-all일 때만 자동 승인을 표시한다.

한국어 상단 한 줄의 왼쪽은 `상태 대기` 또는 `상태 작업 중 HH : mm : ss`, 오른쪽은 `입력 12345 · 출력 678 · 초당 토큰 42.1`이다. 영어 화면은 STATUS IDLE/RUNNING과 INPUT/OUTPUT/TPS를 사용한다. 작업 시간에는 승인 대기·도구·압축이 포함된다. 압축 중에는 `메모리 압축 중`(영어: Compress Memory)과 1~3개의 점을 표시한다. 좁은 창에서는 TPS 등 보조 표시부터 생략한다.

INPUT/OUTPUT은 Provider가 실제 전송한 누적 usage만 사용한다. 수신 전에는 기존 숫자를 유지하고 수신한 적이 없으면 0이다. 호출 중 최신값으로 교체하고 종료·취소 시 마지막 값을 한 번 합산한다. Thinking이 포함된 출력 합계를 중복 계산하지 않는다. 일반 생성·도구 인자·Compaction을 포함하고 연결 진단은 제외한다. 이어하기에서는 저장된 사용량을 복구한다.

TPS는 현재 호출의 실제 OUTPUT을 호출 시작부터 usage 수신까지의 시간으로 나눈 평균이다. 첫 응답 대기를 포함하므로 순수 디코딩 속도와 다르다. 측정할 수 없으면 TPS —이며 재시도마다 초기화한다. 텍스트 길이로 토큰이나 TPS를 추정하지 않는다. [압축 발동량](configuration.md#프롬프트와-compaction)은 별도 계산이다.

선택은 굵기·글자 농도로 표시하고 터미널 기본 배경을 유지한다. 승인 diff의 색상과 드래그 선택의 흑백 반전은 예외다. 도구 기록은 왼쪽 들여쓰기로 이름·실제 인자·결과를 구분하고, 공백뿐인 응답 조각과 블록 사이 불필요한 빈 줄은 화면에서만 정리한다.

## 중지와 후속 요청

작업 중 Esc는 수신한 Thinking·부분 응답·도구 결과를 보존하고 실행을 중지한다. 다음 사용자 메시지는 이 기록과 함께 이어간다. 이전 스트림이나 중단된 도구를 자동 재생하지 않는다. 중지 안내는 입력창 위의 임시 행이며 다음 입력·화면 전환에서 사라진다.

Enter로 보낸 방향 수정은 현재 응답·도구를 마친 안전한 경계에서 다음 판단에 반영한다. 아직 전달하지 못한 메시지는 중지·실패·종료 시 초안으로 복구한다.

Tab으로 예약한 메시지는 현재 작업이 완료된 뒤 별도 요청으로 실행한다. 실패·Esc 중지 시에는 초안으로 돌려놓는다. 이미 예약이 있으면 새 입력은 초안으로 유지한다. 로컬 ! 명령은 예약하지 않는다.

Esc는 선택·후보·키 안내·미리보기부터 닫는다. 승인 화면에서는 후보를 거부하고, 연결 진단 중에는 기존 선택을 유지하며 진단을 취소한다. !new·!quit·Ctrl+C는 worker와 자식 프로세스·연결·DB 자원을 정리한다. !new에서도 이전 대화와 전역 모델 연결은 보존한다.

## 파일 탐색과 참조

!dir은 [ ] / [x] 선택 표시와 Ⓓ / Ⓕ 유형 표식을 사용한다. Space는 참조 선택, ←/→는 폴더 탐색, Shift+Tab은 입력/탐색 포커스 전환이다. 선택한 참조는 Markdown 링크로 입력하며 @는 일반 문자다.

파일에서 Tab은 오른쪽 절반 미리보기, Enter는 전체화면 미리보기다. 폴더에서는 두 키가 아무 동작도 하지 않는다. 미리보기에서 Tab·Enter로 크기를 전환하고 Esc로 닫는다. ↑↓·PgUp/PgDn·Home/End·휠로 스크롤한다. 미리보기를 닫아도 에이전트 작업은 계속된다.

미리보기는 별도 취소 가능한 읽기 작업이며 모델 도구·대화 기록에 추가하지 않는다. 일반 UTF-8 파일을 줄 번호와 함께 최대 처음 16MiB까지 보여주고 생략·바이너리·읽기 실패를 안내한다.

## 실행 범위와 승인

셸과 자식 프로그램은 호스트 사용자 권한을 사용한다. 프로젝트는 기본 작업 디렉터리이며 프로젝트 밖 쓰기·삭제를 OS에서 제한하지 않는다. 전용 파일 도구는 대상 정규화·원본 버전·개인 비밀 경로의 직접 접근 검사를 유지한다. Scope 선택 메뉴는 없다. [호스트 실행과 승인 경계](execution-boundary.md)를 참고한다.

기본 Permission allow-all은 일반 작업의 개별 질문을 생략한다. 위험 작업의 필수 승인과 보호 경로 차단은 [실행 경계](execution-boundary.md)를 따른다. approve에서는 파일 후보·명령 승인을 받으며, 승인 후 대상·원본 버전·내용이 달라지면 거절한다. 분석만 원하면 자연어로 파일을 바꾸지 말고 분석해 달라고 요청한다.

파일 후보는 줄 단위 diff와 앞뒤 3줄 문맥으로 표시한다. 추가는 짙은 초록(#20372C), 삭제는 짙은 적갈색(#422A2D), 글자는 밝은 회색(#D8D8D2)이다. +/−와 변경 전후 줄 번호·EOF·CRLF를 구분하고 긴 변경은 PgUp/PgDn으로 탐색한다. 비교 한도를 넘으면 전체 제거·추가 diff로 표시한다. 명령은 실제 명령·작업 디렉터리, 이동은 원본·대상으로 확인한다. 일반 셸 삭제의 전체 사전 diff는 제공하지 않는다.

파일 조회·검색은 execute_command의 cat·sed -n·nl -ba·rg·find 등을 사용한다. 소스 생성·본문 수정·이동에는 전용 파일 도구를 권장하고 삭제는 rm·rmdir·unlink·find -delete·git rm 등 셸 명령을 사용한다. 셸에서도 생성·본문 변경·이동을 허용하며 호스트 사용자 권한과 Permission을 적용한다. 소스 변경에 전용 도구를 사용하면 실제 diff와 원본 검사도 받을 수 있다. 바이너리·재귀·복수 삭제에도 같은 승인·OS 사용자 권한을 적용한다. 셸의 명령·출력·종료 상태를 기록하고 기존 파일 관측은 오래된 상태로 표시한다. 실패·취소 전에 부분 효과가 있을 수 있다.

execute_command의 실행 인자는 command다. 명령별 시간 인자는 없고 사용자 취소와 전체 작업 예산을 적용한다. 실제 도구 실패는 code·detail·next와 수집한 출력으로 모델에 반환한다. 정책 거절·사용자 취소·저장 실패로 중단하면 후속 호출을 강행하지 않는다.

## 도구 결과와 Markdown

파일 작업은 실제 결과와 편집 전후 줄 위치를 표시하고 명령은 stdout·stderr·종료 코드·상태를 유지한다. 내부 식별자·직렬화 메타데이터는 일반 표시에서 제외한다. 부분 출력에는 생략을 표시하고, 예상하지 못한 형식은 실행 요약으로 안내하며 원본은 저장한다.

write_file·edit_file의 성공에는 고정한 후보의 실제 diff를 표시한다. 생성한 본문과 추가·삭제 줄을 보여주며 줄 번호는 같은 결과 안에서 정렬한다. 미리보기는 최대 16MiB이며 표시용 diff를 모델 문맥에 중복 주입하지 않는다. 실패를 성공한 변경처럼 보여주지 않는다.

줄 번호가 필요한 조회는 nl -ba 등을 사용한다. edit_file의 부분 수정은 현재 원문에서 정확히 한 번 일치하는 old_text/new_text를 사용한다. 모델 결과·저장 기록은 화면 정렬 때문에 변경하지 않는다.

에이전트 응답만 흑백 Markdown으로 표시한다. 제목·강조·코드·목록·인용·링크·표를 지원하고 외부 리소스는 가져오지 않는다. 사용자 입력·도구 출력·파일 본문은 원문이다. 취소선을 사용하지 않아 ~문장~, ~~문장~~, 3~5일을 그대로 표시한다. 코드 블록 공백과 한글·이모지 grapheme은 보존한다. 표시 한도를 넘으면 내용을 자르기보다 원문으로 표시한다.

## 드래그 선택과 복사

대화·입력·주소·모델명·파일 화면에서 드래그해 선택하고 Ctrl+C 또는 전달된 Cmd+C로 복사한다. 선택이 없을 때 Ctrl+C는 종료다. 입력창의 Backspace/Delete는 선택한 입력을 지우며 대화·파일 선택은 원본을 변경하지 않는다. 선택 삭제 안내는 선택 범위 전체가 현재 편집 가능한 입력칸 안에 있을 때 표시한다. 일반 입력·붙여넣기·스크롤·화면 전환·리사이즈는 선택을 해제한다.

복사는 OSC 52를 사용하고 macOS 로컬에서는 필요할 때 pbcopy로 보완한다. SSH에서 원격 Mac의 클립보드를 변경하지 않는다. 터미널이 Cmd+C를 자체 소비하면 Ctrl+C를 사용한다. 화면 밖 드래그 자동 스크롤은 제공하지 않는다. 입력·대화 복사는 자동 줄바꿈을 제거하고 원래 개행·공백을 보존한다.

## Provider 스트림과 복구

SSE·NDJSON은 순차 처리하며 전송 전체와 단일 프레임 크기에 고정 제한을 두지 않는다. 비스트리밍 JSON·실행 문맥·인자·저장에는 [각 본문 한도](configuration.md#본문-한도)를 적용한다. 수신 중에는 응답과 Thinking을 갱신하고 미완성 도구 인자는 일반 응답에 표시하지 않는다.

모델 생성의 무수신 한도는 기본 600초, 메타데이터·연결 진단은 기본 3분이다. 수신이 계속되면 다시 기다리며 소비자 처리 시간에는 읽기 대기 타이머를 멈춘다. DNS·연결·TLS 초기화 제한과 사용자 취소는 별도다.

복구 가능한 전송 오류는 최대 3회 시도한다. 기본 대기는 250ms·500ms이고 Retry-After는 최대 30초를 반영한다. 부분 응답·Thinking 초안은 재시도 전에 초기화하고 실행한 도구는 재생하지 않는다. 최종 오류는 시도 횟수·HTTP 상태·실제 오류와 함께 표시하며 비밀값을 제거한다. 로컬 정책·인자·저장 실패와 취소는 즉시 처리한다.

서버 context·출력 한도·Thinking의 보장 범위는 [모델 프로파일](model-profiles.md#서빙-한도)을 참고한다. 연결 진단과 모의 서버 검사는 모든 실제 서버의 장시간 호환성을 보장하지 않는다.

## 큰 출력과 자동화

도구 결과는 기본으로 모두 펼쳐 보이며 Ctrl+O로 전체를 접거나 펼친다. 접으면 도구 이름·대상·실행 상태·종료 코드나 변경 요약만 남기고 stdout·stderr·본문·diff를 숨긴다. Thinking·에이전트 응답·사용자 입력은 그대로 유지한다. 전환 상태는 입력창 위에 표시하고 긴 출력은 PgUp/PgDn으로 읽는다. 펼칠 대상이 있을 때 하단·F1 안내에 현재 동작을 표시한다. 모델에는 stdout·stderr 각각 32KiB의 앞뒤 발췌와 재조회 로그 경로가 전달된다. cat·sed로 필요한 부분을 다시 읽을 수 있으며 이 로그는 현재 Executor가 종료될 때 제거된다. 수집 원본은 세션 DB와 JSONL export에 보존한다. 스트림별 16MiB 수집 한도를 넘으면 생략을 명시한다.

v --print는 최종 답변만, v --mode json은 이벤트를 stdout에 출력한다. 파이프 stdin을 요청에 포함할 수 있다. v --session ID --print로 재개하고 v --session ID --export로 시간순 원본 JSONL을 내보낸다. 같은 도구·저장·승인 정책을 사용하며 필요한 승인을 받을 수 없으면 실행을 차단한다.
