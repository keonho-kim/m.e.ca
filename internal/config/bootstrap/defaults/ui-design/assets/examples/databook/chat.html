샘플 인터뷰 메모: 보안 검토 문서가 여러 위치에 나뉘어 있어 준비할 항목을 한 번에 파악하기 어려웠음.

조회 범위 예시 
SELECT company_name,
       onboarding_stage,
       elapsed_days
FROM accounts
WHERE onboarding_stage
      = '보안 검토';

디자인 예시 안내

이 예시는 화면 구성과 상호작용 형태를 살펴보는 정적 프론트입니다. 데이터, 문서, 답변과 검토 결과는 모두 샘플 콘텐츠입니다.

실제 데이터베이스 연결, AI 요청, 편집·저장, 파일 내보내기는 구현하지 않았습니다. 입력 내용은 저장하거나 전송하지 않습니다.
