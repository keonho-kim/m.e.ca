# Typography, material, boundaries and assets

Read only the relevant findings; preserve intentional themes and the actual product task. Source revision and finding classification are owned by the [anti-slop map](../anti-slop.md).

## 2. Typography must identify readable roles

The source critiques reflex font choices, flat hierarchy, oversized/italic display heroes, crushed tracking, excessive capitals, poor wrapping and tiny functional text. Its thresholds are not a universal type scale: operations and public introductions need different roles.

Define page, section, body, label, data and support roles. Use actual Hangul coverage for Korean work. Test real text, mixed identifiers, units and fallback fonts. Keep display expression separate from operating labels; do not impose Latin tracking or uppercase habits on Korean copy.

Reading measure and table width are different decisions. Fix heading rhythm and meaningful wrapping without forcing all content into identical containers. Do not shrink text or hide overflow just to fit a screenshot.

## 3. Color and material need a deliberate reason

The source warns about reflex purple/cyan palettes, warm-cream palettes, gradient text, halos, glows, stripes and decorative grids. The problem is unchosen convergence, not proof that a hue is inherently wrong.

Choose semantic colors and material from the subject or existing system. Verify actual foreground/background combinations, focus and selected/error states. Text over a colored or transparent region must remain legible. Preserve structure in reduced effects or an opaque fallback.

A requested futuristic palette or glass layer earns a contextual assessment. It does not earn endless glowing panels. An intentional hard shadow can suit a material; applying it to every unrelated region still adds noise.

Source cues: `ai-color-palette`, `cream-palette`, `gradient-text`, `dark-glow`, `radial-halo`, `radial-spotlight-glow`, `gray-on-color`, `low-contrast`, `hard-offset-shadow`, `repeating-stripes-gradient`, `codex-grid-background`.

## 4. Boundaries and spacing reveal relationships

Thick accent strips, accent borders on rounded cards, nested elevation, identical gaps and border-plus-wide-shadow rows can decorate containers without explaining their role.

Group related work tightly and separate distinct tasks. Give real regions a readable inset. Choose boundary, surface change, whitespace or elevation according to the relationship. A floating inspector may need a treatment that a row of ordinary panels does not.

Check scroller edges and positioned layers. Menus and tooltips must not be cut off by a clipping rule added to hide another layout problem. Fix the offending geometry instead of obscuring content.

Source cues: `side-tab`, `border-accent-on-rounded`, `monotonous-spacing`, `cramped-padding`, `body-text-viewport-edge`, `edge-flush-cards`, `text-overflow`, `text-occlusion`, `clipped-overflow-container`, `gpt-thin-border-wide-shadow`.

## Inspect the role before changing a token

A compact file title and large authored content can form a strong application hierarchy even when a generic headline ratio disagrees. Real object names may wrap; concise commands and readable identity need different treatment. A caption belongs to its media, while a section heading introduces what follows.

Neutral minimal surfaces need adequately strong functional ink and visible action/selection. Distribute accents by real role instead of washing every panel in pale color or assigning random hues. Treat category, focus, selected and completed as separate meanings.

Tables can put inset responsibility on cells, an editorial surface on its reading container and a popup on one floating layer. Do not add duplicate wrapper padding or remove useful boundaries merely because a broad source heuristic sees a repeated recipe. Inspect the painted geometry and user cost.

## 7. Assets and rendering must reach the user

Primitive-shape placeholder scenes, arbitrary organic CSS masks, buried rasters, broken images, script errors and failed reveals need different corrections. Intentional diagrams, geometry, maps and data graphics are legitimate; pictorial filler does not establish product meaning.

Use suitable real or explicitly illustrative material. Keep its intended contribution visible instead of hiding a large file beneath an opaque wash. Provide a useful missing-media state. Content remains available when animation fails. Fix actual script errors before judging visual success.

Source cues: `shape-assembled-illustration`, `organic-clip-path`, `buried-raster`, `broken-image`, `script-error`, `content-hidden-at-rest`.
