# Derive a direction from the product

Use for new identity, authorized redesign or meaningful visual exploration. Preserve the incumbent system for ordinary feature work. Explain a direction through the audience's work and actual content, not by assigning a skin to an app category.

## Work across independent axes

Choose the leading information, frame/proportions, type roles, geometry, density, image treatment, color emphasis and motion character. Change the axes that serve the task; do not force every axis to be unusual. Familiar controls and quiet type can be correct.

A palette change is a valid refinement but does not by itself produce a different composition. Conversely, meaningful identity does not require a new layout on every page: one product keeps stable action vocabulary and shared visual roles.

| Direction | What carries it | Useful question / cost |
| --- | --- | --- |
| Precise operational | Alignment, readable density, clear scope and nearby actions | Does repeated work stay quick without becoming cramped? |
| Corporate/enterprise | Consistent hierarchy, predictable operation, measured emphasis and truthful feedback | What communicates trust beyond a generic blue palette? |
| Editorial | Reading sequence, title/body contrast, image/caption relationship and considered emphasis | Does expressive scale help understanding or delay frequent inspection? |
| Media-led | Genuine artifacts lead while chrome and metadata support them | Which facts must stay visible alongside the image? |
| Documentary/tactile | Material, natural content and calm rhythm | Are control boundaries and state still unmistakable? |
| Bold graphic | Confident scale, shape, edges and purposeful color fields | Can ordinary actions and essential labels remain familiar? |
| Spatial/creative | Continuous work, direct relationships and deliberate object tools | Does position mean something worth the orientation cost? |
| Technical/forward-looking | Real systems, notation, precision and controlled signals | Are the instruments meaningful rather than decorative telemetry? |

These are interpretations to combine or extend, not a command menu or exhaustive presets. “Premium”, “corporate” and “modern” need translation into concrete decisions; they do not prove that a matching catalog theme exists.

## Combine by role

A minimal shell and editorial detail can share type/color roles while giving content different scale. Glass can explain retained context behind a toolbar while code and forms stay opaque. Persistent marks can identify selected controls while reading surfaces stay calm. Keep one intelligible system rather than applying several materials to every region.

Choose light/dark from intended use, visual adaptation, content and the actual brief. Technical tools are not automatically dark; a library is not automatically warm; an office editor need not borrow another service's exact palette.

Use multiple accents where distinct actions, categories or real states need recognition. Keep their meaning stable and supporting text readable. Color variety is not a substitute for hierarchy, and uniform neutral treatment can also obscure differences.

## Ground the choice

Inspect the actual product and relevant supplied or primary visual material. Name what transfers: information priority, density, navigation scope, control/content separation, image scale or state feedback. A brand reference does not authorize copied logos, claims or a full visual identity.

For a consequential open choice compare a small set of materially different arrangements with the same content and task. Do not impose a fixed three-option ritual on precise requests. Give a recommendation, its expected benefit, cost and check. An inherited system may already settle the direction.

## Review what makes it specific

At the same content/state/viewport compare reading order, silhouette, object scale, action placement, type, grouping, image role and interaction. Ask whether renaming the product would leave an interchangeable design. A grayscale view can expose weak hierarchy, but color may legitimately carry part of the identity.

Record the useful rationale, not a diversity score. Treat expected benefit as a hypothesis until observed. The [same-task studies](visual-studies.md) illustrate several choices; their filenames, palettes and implementation are not requirements for the next product.
