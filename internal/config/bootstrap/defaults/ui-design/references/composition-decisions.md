# Choose what stays visible and what comes first

Use when an arrangement does not fit, several entry points are plausible or the user requests diversity. Keep the task, real objects and operation meanings stable while exploring information order and presentation. Do not multiply routes to make a cosmetic correction appear substantial.

| Frame | Benefit | Cost to evaluate |
| --- | --- | --- |
| Persistent global navigation | Stable access across substantial areas | Width and attention taken from the work |
| Top navigation | Wide work with a shallow peer set | Deep destinations need another deliberate path |
| Master-detail | Repeated inspection with collection context | Smaller detail/table measures and pane scrolling |
| Independent detail/reader | Sustained content or editing with more scale | Travel back to comparison and restored return context |
| Editorial/media-first detail | Subject, image and reading sequence become the focus | Metadata or actions may move below the first viewport |
| Time/resource-first | Chronology and conflicts can be compared directly | Dense scales, labeling and reliable availability matter |
| Full canvas | Position and direct manipulation carry relationships | Orientation, scale, non-drag access and alternate reading |
| Multiple task panes | Source, input, result or tools can be consulted together | Minimum useful widths and focus/scroll ownership |

These arrangements can combine. Each added pane or sticky region must answer a real question. Preserve sufficient space for the leading object; do not solve a crowded layout by making essential type tiny.

## Choose the entry point from the person

The same reservation may start with atmosphere and capacity, with date/resource comparison, or with familiar grouped input. Those approaches serve different knowledge and frequency. A public discovery page may earn large photographs; a repeat user may need direct fields and a persistent summary.

The same content item may be an editorial destination for reading or a compact inspector for rapid asset administration. Large imagery is a deliberate tradeoff, not automatically better detail design. Keep decisive metadata alongside the work when the decision needs simultaneous inspection.

The same data can become rows, a board or a chronology only when that organizing axis helps the task. A spatial canvas needs meaningful placement; otherwise a collection is easier to scan and revisit.

## Establish invariant meaning

Across genuine alternate views retain object identity, query/selection, relevant drafts, operation scope and actual results. A change in composition does not create a new business model or confirm persistence. For a design-only comparison, keep representative data and interaction assumptions explicit without building a backend to equalize the studies.

Global destinations, object navigation and local view filters are independent. An outline or filmstrip navigates the artifact; a status filter narrows a collection; an execution list reports work. Similar shapes do not make them interchangeable tabs or wizard stages.

## Let content choose its representation

Use genuine imagery when appearance helps the choice, with decisive captions and useful failure alternatives. Use an actual product view for explanation, a chart for a real quantitative question and a diagram for real relationships. Type and ordinary content can lead when imagery adds little. Decorative empty frames are not a request for invented proof or scenes.

## Compare fairly, then adapt

Hold brief, content, state and viewport constant when evaluating alternatives. Compare leading information, simultaneous visibility, memory burden, action placement, retained context and recovery. Then inspect type, rhythm, material, color and motion. Novelty, fewer clicks or a different accent alone cannot establish a better task path.

State audience/task → leading information → arrangement → expected benefit/cost → observable check. Use actual feedback to revise assumptions. The concrete implementations in [visual studies](visual-studies.md) are optional evidence, not a requirement to reproduce their routes or client modules.
