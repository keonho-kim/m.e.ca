# Optional application studies: inspect a decision

This is a level-2 source map, not an application specification. Choose a study because its information relationship helps the current task. Read its composition, benefit and cost, then adapt the target product's content, system, framework and service scope. Do not copy fictional names, page counts, palettes or module boundaries as requirements.

These local HTML/CSS/Vanilla JS studies run without external runtime packages/fonts/CDNs. Approval, DB, research and office views are design shells; Archive/booking retain bounded local demonstrations. Those limits describe the studies, not a ban on real integration in a functional task. For browser inspection serve assets/examples as a static root; no gallery or extra command is required.
