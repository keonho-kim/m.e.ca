역할이 있습니다.

선택과 맥락을 유지하면서 조작·정보·상태를 연결합니다. 애니메이션을 꺼도 기능과 의미는 같습니다. 이 페이지의 수동 미리보기는 실제 서버 처리 상태가 아닙니다.

Hamburger Morph + Side Drawer

좁은 창에서 보조 탐색을 펼칩니다. 전체 탐색은 목적에 맞춰 상단 메뉴나 사이드바에 둡니다. Escape와 닫기 뒤에는 열었던 위치로 돌아옵니다.

누르면 탐색을 엽니다
라이브러리에서 찾기 운영 요청으로 이동

오른쪽 더 보기에는 Staggered Dropdown이 적용됩니다. 이동 거리와 지연은 작게 제한하고 키보드 접근을 유지합니다.

Staggered entry + Skeleton

알려진 구조를 기다리는 동안 Pulse 또는 Shimmer를 사용합니다. 실제 로컬 응답이 끝나면 스켈레톤을 치우고 내용의 순서만 짧게 드러냅니다.

추가 대기 시간을 만들지 않습니다. HTTP로 열어야 자료 요청이 작동합니다.

Blur-up Image

같은 원본에서 만든 40px 프리뷰를 사용합니다. 해상도가 준비되면 교체하고, 캐시에서 준비된 이미지는 즉시 보여줍니다. 레이아웃 비율은 먼저 확보합니다.
