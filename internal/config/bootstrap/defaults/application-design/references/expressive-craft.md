# Preserve useful expression during anti-slop review

Use this alongside the existing detector analysis when review is flattening a deliberate identity or the user asks for more diversity. The 62 source cues remain prompts to investigate. Classify an actual defect, an unchosen default and an intentional decision separately.

## Positive cases and targeted corrections

| Expression | When it has a real role | Fix the defect while retaining the idea |
| --- | --- | --- |
| Large or contrasting display type | A clear subject, editorial opening, deliberate document hierarchy | Improve Hangul wrapping, scale at narrow widths and proximity to a useful action; retain the earned typographic contrast |
| A strong field of brand color | A principal choice, recognizable navigation or an explicit expressive identity | Check on-color text, focus and selected/error meanings; preserve the deliberate emphasis instead of bleaching the whole product |
| Hard shadow or sharp border | A raised sheet, tool layer or a coherent graphic language | Reduce ambiguous or repeated elevation; keep the meaningful boundary where it explains the layer |
| Gradient or translucent material | A genuine continuous value, controlled media overlay or contextual tool layer | Fix composite contrast, legibility and fallback; do not assume every gradient or glass layer is a defect |
| Asymmetry and unequal scale | Real differences in importance, image proportions or reading sequence | Restore semantic order, useful comparison and smaller-window behavior; retain subject-specific proportion |
| Grids and geometric marks | Coordinates, measured artifacts, actual charts, canvas alignment or technical notation | Remove unrelated telemetry/decoration; keep geometry that helps interpret or manipulate the work |
| Familiar fonts, cards or tabs | The existing identity and learned task are served well | Correct weak hierarchy, meaningless nesting or hidden comparison; do not replace a familiar primitive merely to look original |
| Texture or warmth | The brief and subject benefit from material distinction | Keep readable work, explicit control boundaries and clear selection; do not treat cream, paper or soft material as automatic quality |
| Spacious or compact composition | Reading/focus or rapid comparison genuinely requires that rhythm | Remove empty filler or cramped essential text at its cause; keep the density that serves the work |

These are permissions to reason, not exemptions from legibility, truthful state, accessibility or the requested scope. An intentional mistake remains a mistake. A warning should lead to a precise correction rather than a universal ban.

## Preserve hierarchy while reducing noise

Minimalism can keep decisive accents, strong type contrast and meaningful object scale. Editorial detail can lead with a subject and imagery while its controls stay compact. Neither requires bleaching all labels or copying a fixed serif/cream palette. Several accents can clarify distinct roles without turning every region into a primary signal.

When a result feels flat or generic, inspect the working object, reading order, grouping and density before adding another material effect. A local control can gain clearer focus/selection while a surrounding reading surface remains calm. Preserve the useful direction and correct the actual comprehension or operating cost.

## Describe a useful correction

Record the location and observed user cost, the actual cause, the smallest correction, the expression being retained and the relevant check. For example: an editorial Korean title breaks into isolated syllables at a narrow width → improve phrase wrapping and scale → retain serif hierarchy and the image-led layout → inspect the same content/width again.

A second example: a dense schedule gives selected slots and ordinary rows the same treatment → make actual selection explicit with text, boundary and functional emphasis → retain aligned compact rows and tabular time → test selection and keyboard access, including unavailable choices.

Do not call a design generic solely because it uses a well-known pattern, or distinctive solely because it has unusual decoration. Evaluate whether the actual subject, content relationships and principal task are understandable.

## Give motion a coherent character

| Intent | Possible application | Keep intact |
| --- | --- | --- |
| Direct and precise | Repeated operations, schedule selection, high-frequency keyboard work | Immediate logical state, a short settled response and no repeated entrances |
| Soft and responsive | A fitting tactile choice or direct spatial manipulation | Fast access to the target, restrained settling and legible labels; real springs need an appropriate primitive |
| Spatial continuity | Drawer, inspector, object selection and related parent/detail work | Actual identity, direction, focus and interruption |
| Editorial rhythm | A meaningful initial group or a considered public reveal | Ready content, bounded total delay and a useful static/reduced-motion version |

Choose temporal behavior from the relationship, not an asset’s settings. Direct spatial input should not trail behind decorative easing, and a repeated list refresh should not replay a brand entrance. A short opacity change, an actual spring and a shared snapshot solve different problems; none is mandatory to make a page look finished.

Choose a temporal vocabulary per product or meaningful region, then reuse it consistently. An operational form and an occasional celebratory moment can have different intensity for a reason. Do not add a configurable motion framework merely to expose a selector.

## Verify expression and operation together

Capture the real implementation at the intended viewport and state. Compare hierarchy, silhouette, type, spacing, image role and emphasis against the brief/reference. Interact with the principal controls, including failure, interruption, keyboard and available reduced-effects checks. Distinguish source review from runtime evidence.

Inspect whether a proposed correction improves the identified cost while keeping the valid direction. If the result becomes another neutral sidebar-and-card layout without a task reason, revisit what the review erased. A detector count or agent preference cannot prove improvement.

The same-brief studies illustrate choices, not trained-model performance or user preference. Use realistic requests and compare actual outputs when evaluating whether a skill produces better decisions. Do not add a score database or invoke independent reviewers without authorization.
