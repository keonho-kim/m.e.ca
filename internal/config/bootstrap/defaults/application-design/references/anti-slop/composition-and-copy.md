# Composition and product copy

Read only the relevant findings; preserve intentional themes and the actual product task. Source revision and finding classification are owned by the [anti-slop map](../anti-slop.md).

## 1. Structure must come from the task

Equal icon tiles, nested cards, repeated text and unbalanced openings often indicate that a template chose the content. Name this application's objects, decision and main path, then give each region a job. Use tables for comparison, boards for meaningful state movement and evidence for actual analytical questions.

Warning signs include four KPI cards on every home, a feature tile for every paragraph, repeated status text, empty inspectors and a giant heading above an unusably small work area. Correct the hierarchy or remove the unnecessary region; changing card sizes alone does not fix the problem.

Source cues: `nested-cards`, `icon-tile-stack`, `repeated-container-text`, `first-viewport-column-overflow`.

## Make variation explain a different job

Distinguish global areas, project modes, object navigation and local views. Repeating the same left rail and card frame for unrelated products can conceal their real differences; banning every useful side pane is the opposite mistake. A schema tree, outline or filmstrip can earn space through task relationships.

Choose operational inspection versus editorial reading from what must be visible together. Large media and a narrative title may justify more scrolling; frequent metadata comparison may need a retained inspector. An asset's arrangement is one tradeoff, not the default for its whole app category.

## 5. Copy describes this product

The source flags generic marketing phrases, repeated manufactured contrasts, saturated em-dash cadence, decorative eyebrows, numbered section labels and dismissive “theater” phrasing. Diagnose repetition and missing meaning, not punctuation alone.

Write product nouns and concrete action verbs. Headings introduce content; labels identify something useful. Numbering is justified by a real sequence or reference system. Repeated decorative kickers cannot replace hierarchy. Korean action labels should state what happens rather than use 확인 for every operation.

Do not invent customers, revenue, usage, security claims, testimonials, integration support or success. Fixtures remain illustrative. Factual gaps are unresolved input, not spaces to fill with impressive claims.

Source cues: `hero-eyebrow-chip`, `kicker-above-heading`, `numbered-section-labels`, `em-dash-overuse`, `marketing-buzzword`, `aphoristic-cadence`, `theater-slop-phrase`.
