# Forum implementation Q&A

## What happens to children when a parent is deleted?

If replies stay useful and visible, keep an authorized placeholder and the reply structure while removing the parent's content. If the product removes the subtree, apply that decision to direct links, search, notifications and counters. Test both a removed reply and a hidden whole thread.

## How should unapproved drafts look?

Give the author and reviewer their respective views and actions. Keep pending posts outside public results, counters and notification fan-out. Use a specific review result and preserve a recoverable draft if the author can correct it.

## How do pinned and sorted pages fit together?

Choose whether pins form a separate bounded group or occupy a defined part of the same ordering. When paging by a cursor, keep the same sort and scope and exclude IDs already shown in an independent pin group. Refresh deliberately when a category change invalidates the cursor.

## What should a link to a moderated reply do?

Resolve the reply under the current viewer's permissions. For an inaccessible reply, show the parent topic or a consistent unavailable state where allowed. Keep the response from disclosing text or existence that the viewer cannot learn.
