# Commerce Do & Don’t

| Decision | Do | Don’t |
| --- | --- | --- |
| Accepted price | Record the agreed price, currency, quantity and terms with the order. | Recalculate old purchases from the latest catalog. |
| Capacity | Validate available quantity where it is claimed and model release if held. | Guarantee inventory from a cached product page. |
| Duplicate events | Reconcile provider and application identities before another side effect. | Charge, fulfill or refund again because an acknowledgement went missing. |
| Partial outcomes | Track line quantities and derive a meaningful summary from real results. | Mark an entire order fulfilled or refunded from one successful line. |
| Marketplace access | Enforce scope when a buyer, seller or operator reads or changes each record. | Expose another seller's items or private details in a shared order view. |
| Recovery | Give the buyer a durable status path for uncertain results. | Ask for another purchase before the first commitment is resolved. |
