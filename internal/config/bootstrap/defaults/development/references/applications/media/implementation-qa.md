# Media implementation Q&A

## Can media be public while some renditions process?

Decide from the minimum playback and publication contract. If a suitable rendition is ready and partial quality is permitted, show the ready options and what is pending. If publication requires checks or a rendition, keep release gated until its accepted outcome.

## What should a saved playback position mean?

Bind it to the media version and the viewer where required. Choose when a position is saved and whether a replaced source resets or maps it. A learning workflow can require stronger completion evidence than the last seek position.

## How should buffering and reconnect affect the experience?

Keep the intent to play or pause and the last meaningful position. Display buffering or failure from observed playback signals. Reauthorize and reload the necessary source when required, and allow recovery without restarting unrelated media work.

## What is the effect of withdrawing media?

Define access to playback, previews, captions and share links once withdrawal takes effect. Check the lifetime for previously issued references and already delivered bytes. Identify what editorial or processing state remains visible to authorized operators.
